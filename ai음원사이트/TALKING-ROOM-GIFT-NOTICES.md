# 토킹룸 선물 채팅 알림 — 2026-10-19

선물 전송 성공 후 서버 영수증을 받은 토킹룸에 선물 알림을 추가한다.

표시 예: `A님이 B님에게 막대사탕 ×1을 보냈습니다.`

- 보내는 사람, 받는 사람, 선물 이름, 수량, 시간을 표시한다. 선물 이미지와 구분된 배경을 사용한다.
- 기존 애니메이션을 유지하면서 채팅 목록도 실시간으로 새로 읽는다. 이미 조회 중일 때 들어온 이벤트는 후속 조회로 반영한다.
- 선물 차감/정산은 기존 서버 장부를 사용한다. 잔액 부족 등 전송 실패 시 알림을 만들지 않는다.
- 영수증 ID를 기준으로 중복 알림을 막는다. 영수증 표시와 채팅을 함께 저장한다. 일반 채팅 요청으로 선물 알림을 위조할 수 없다.
- 기존 채팅과 같은 순번/입장 경계를 적용한다. 늦은 입장과 퇴장 후 재입장에는 이전 알림을 보내지 않는다. 연결 복구 시에는 이미 볼 수 있었던 알림이 유지된다.
- 최근 100개의 대화/선물 알림을 방에 임시 보관하고, 방 종료 시 비운다. 별도 영구 채팅 기록은 추가하지 않는다.
