# AIFECT 앱·웹 개선 — 2026-09-29

Android 2.5.0(versionCode 13)과 동일한 API를 사용하는 웹의 변경 내역이다. 기존 로그인·결제·광고 설정과 서명 키를 보존했다. 운영 결제 활성화나 유료 선물 전송은 수행하지 않았다.

| 2 프로필 수정 | 사진에서 편집 화면으로 이동하며 선택한 사진·공개 닉네임·소개를 서버에 저장한다. |
| 3 보관함 내 페이지 | 프로필, 내 커버, 좋아요, 플레이리스트, 팔로잉·팔로워를 연결했다. |

| 20 공개 닉네임 | 프로필·댓글·선물·크루·DM·로그인 표시에서 공개 이름 정책을 통일했다. 사용자가 선택한 이름을 우선하며 자동 복사된 OAuth 실명은 공개하지 않는다. 원본 사용자 이름은 덮어쓰지 않는다. |

| 27 활동 보상 | 별도 보상 화면에서 기존 출석·커버 공개·5곡 감상·댓글 조건과 지급 API를 사용한다. 기존 지급량과 중복 방지를 유지했다. |

## 크루 기본 규칙

레벨별 경험치 기준은 0 / 100 / 500 / 1,500 / 3,000이며 정원은 요청한 10 / 20 / 50 / 100 / 150명이다. 멤버별 하루 첫 채팅은 10XP, 가입 후 공개한 곡은 곡당 50XP다. 규칙은 `shared/crews.js`에서 조정한다. 같은 채팅 전송 재시도, 재가입, 동일 곡으로 중복 경험치를 얻을 수 없다. 크루장이 탈퇴하면 가장 오래된 멤버에게 권한을 이전한다.

## 검증

- 서버·공유 코드 검사 154개 통과. 프로필 저장, 공개 이름 보호, 사진, 크루 정원·접근 권한·경험치, DM 격리·읽음·중복 전송, 삭제 댓글, Premium 다운로드와 스트리밍을 포함한다.
- 브라우저에서 프로필·크루·채팅·DM·출석 보상·정산을 로컬 실제 API로 검사했다. 테스트 음성으로 마이크 PCM 저장, 가사 6.125초 재녹음과 프리롤 구분, 효과 복원, 출력 WAV 음성 포함을 확인했다.
- 휴대폰 폭 390px 및 글자 200%에서 가로 넘침과 선물 시트 하단 배치를 검사했다.
- Android 에뮬레이터 통합 검사 21개, 글자 200% 주요 동선 추가 검사 3개, JVM 검사 19개 통과. debug/release 빌드와 lint 오류 0개.
- APK는 기존 직접 설치 APK와 동일한 인증서로, AAB는 기존 업로드 인증서로 서명했다. 원래 키 파일의 SHA-256이 변경되지 않았음을 확인했다.

마이그레이션 `0017_crews_messages`와 `0018_public_nickname`은 테이블·컬럼을 추가한다. 운영 사용자 데이터 삭제나 이름 일괄 덮어쓰기는 없다. 실제 휴대폰 마이크·이어폰·Bluetooth 청음, Play Console 업로드는 이 검증에 포함하지 않았다.
