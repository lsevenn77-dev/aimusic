# 녹음 편집 · 공개 경험치 제한

## 녹음 편집

- 기존 녹음·믹서·MP3 256kbps 저장을 유지한다. 편집 화면에서는 싱크·노이즈·음색과 소리 설정을 보여준다.
- 프리미엄의 ‘일부 구간 재녹음’ → 별도 가사 선택 화면 → 3·2·1 → 선택 구간 녹음 → 결과 확인 → ‘이 녹음 사용’ 순서다.
- 시작이 0초여도 3초를 온전히 센다. 마이크 준비·권한 승인·반주 다운로드를 마친 뒤 오디오 시계로 센다.
- 원본 PCM은 결과 확인 중 바뀌지 않는다. 수락할 때만 앞뒤를 보존해 교체하고 기기 초안에 저장한다. 취소·화면 이탈·마이크 준비 실패는 원본을 유지한다.
- `GET/POST /api/karaoke/:id/rerecord`는 로그인, 서버 프리미엄, 공개 원곡과 MR/가사 준비, 가사 인덱스와 시간 범위를 검증한다. 진입·녹음 시작·결과 수락 시 다시 검사한다. 일반 녹음 권한은 변경하지 않는다.
- 후보 재생은 후보 PCM에 같은 효과를 적용한다. 저장·기존 녹음 미리듣기의 효과 캐시와 원음을 혼동하지 않는다.
- 로컬 브라우저 QA는 `tests/preview-recording.mjs`와 합성 마이크만 사용한다. 실기기 음질과 Bluetooth 지연 검증을 대신하지 않는다.

## 경험치

- 제작곡·커버·듀엣 공개의 개인 보상은 합산 3회/회원/한국 시간 날짜다. 감상·댓글·크루 대화의 기존 일일 보상은 그대로다.
- 기존 곡별 `player_xp` 고유 키를 유지하고 D1 트리거로 동시 공개에서도 한도를 검사한다. 과거 공개 보완은 최초 공개 시점을 사용한다.
- 크루의 완성 작품/협업 기여는 크루원별 합산 5회/한국 시간 날짜다. 같은 작품의 중복 기여를 한 번으로 센다. 초과 작품도 증거를 남겨 재시도·크루 이동으로 한도를 우회하지 못하게 한다. 기존 미션별 보상량은 유지한다.
- 크루는 XP와 최소 성장 기간을 모두 충족해야 승급한다. 레벨 1~10의 최소 기간은 0·7·14·30·45·60·90·120·150·184일이다. 184일은 어떤 달에 시작해도 6개월 이상이 되도록 잡았다. 기준 시각은 기존 `crews.growth_started`다.
- 이미 적립한 경험치와 달성한 `highest_level`은 보존한다. 개인 레벨의 XP 곡선은 바꾸지 않는다. 크루 정원과 액자 지급·장착 권한도 같은 성장 기간을 적용한다.

## 운영 DB 승인 대상

- `0074_lean_hedge_knight.sql`: `crew_growth_events.credited` 열, 개인 공개 3회 제한 트리거, 크루 기여 5회 제한 트리거.
- `0075_perfect_vulcan.sql`: 크루원별 날짜 조회용 인덱스. 새 테이블·회원/음원/결제/정산 데이터 삭제 없음.
- 기존 이력은 기본값 1로 보존한다. 배포는 두 migration의 운영 적용을 별도로 승인받은 후 기존 Sites 프로젝트에서만 한다.
- 되돌릴 때는 이전 Sites 버전을 공식 도구로 게시한다. 추가 열/인덱스는 이전 코드와 호환된다. 한도까지 되돌려야 하면 새 전진 migration으로 트리거를 해제한다. 적용된 migration을 수정하거나 XP를 삭제하지 않는다.
