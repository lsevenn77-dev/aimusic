# AI 가수 대표 이미지 선택 호환성 보완

## 범위와 증거

- 신고: 모바일 웹 AI 가수 상세 페이지에서 `대표 이미지 변경`을 눌러도 사진 선택창이 열리지 않음.
- 기존 216번 소스의 투명 파일 입력을 겹친 label 방식은 로컬 Chromium의 모바일 폭에서 선택창이 열렸음. 실제 신고 기기의 실패 원인은 재현하지 못했으므로 특정 브라우저 결함으로 단정하지 않음.
- 다른 업로드 화면, 결제, 녹음, 공개 권한, DB 구조는 변경하지 않음.

## 변경

- 실제 `type="button"`으로 터치/키보드 입력을 받고 같은 클릭 처리 안에서 연결된 파일 input의 `click()`을 즉시 실행한다. 네트워크 요청·타이머·비동기 대기 후 선택창을 열지 않는다.
- 버튼 위 투명 input 겹침을 제거하고 최소 44px 터치 높이를 확보한다.
- 편집·저장 중 버튼과 input을 함께 잠그고 취소·실패 후 모두 해제한다. 파일 값을 초기화해 같은 사진을 다시 고를 수 있다.
- 원형 편집·WebP 저장·소유자 서버 검증은 기존 경로를 그대로 사용한다.

## 검증

- 로컬 SQLite/R2 메모리 fixture에서 실제 파일 선택창 → 원형 편집 → 취소 → 같은 사진 재선택 → 저장 → 새 버전의 800px 이미지 표시 확인.
- PC 1440×900, 모바일 390×844, 320px, 768px 레이아웃 점검. 캡처: `work/releases/artist-picker/`.
- 동기 클릭, input 클릭 재귀 방지, 저장 중 중복 실행 방지, 취소 후 재선택 회귀 테스트 추가. 기존 소유권·이미지 저장·크롭 테스트 유지.
- 사용 가능한 브라우저는 데스크톱 Chromium 기반이다. 실제 Android Chrome, Samsung Internet, iOS Safari 기기 검증은 미완료. 운영 적용 후 신고 기기에서 선택창이 열리는지 재확인이 필요하다.
- 운영 사용자 사진에는 테스트를 수행하지 않음. 운영 배포는 이 후보의 별도 승인 후 진행한다.
