# AIFECT 공통 디자인 — 2026-10-17

사용자가 제공한 DESIGN SYSTEM 이미지의 라벤더·민트 색상과 얇은 선 아이콘을 웹 공통 테마에 적용했다.

## 색상과 형태

| 역할 | 값 |
| --- | --- |
| 라벤더 | `#B7B6FF` |
| 연보라 | `#D6BAFF` |
| 민트 | `#AEEBDF` |
| 기본 배경 / 패널 | `#0C121B` / `#131B26` |
| 보조 배경 | `#1F1F26`, `#2A2A35` |
| 테두리 / 비활성 | `#3A3A48` / `#6B7280` |
| 본문 / 보조 글자 | `#F5F5FC` / `#A9B0C1` |
| 강조 버튼 글자 | `#171B2B` |
| 성공 / 경고 / 오류 / 정보 | `#4ADE80` / `#FACC15` / `#F87171` / `#60A5FA` |

주요 버튼과 선택 상태: 105도 그라데이션, 연보라 → 라벤더(48%) → 민트. 밝은 배경에는 어두운 글자를 쓴다. 보조 버튼은 어두운 배경과 가는 테두리를 사용한다. 키보드 포커스는 민트 2px이다.

아이콘은 24×24 좌표계, 기본 두께 1.6, 둥근 끝과 연결부를 사용한다. 카드/입력창/큰 패널 모서리는 각각 16/12/20px, 작은 요소는 8px, 원형 아바타와 알약 버튼은 원형을 유지한다.

## 구현 위치와 범위

- `dist/design-system.css`: 기존 스타일 다음에 로드하는 공통 토큰과 컴포넌트 스타일. 사이드바, 버튼, 입력창, 카드, 선물함, 커뮤니티, 채팅, 재생바, 녹음 설정에 적용.
- `dist/design-system.js`: 믹서/볼륨 슬라이더의 실제 값과 프리셋 변경에 맞춰 색상 채움만 갱신. 재생 탐색 및 오디오 처리는 기존 로직에서 담당.
- `dist/icons.js`: 홈/검색/마이크/알림/프로필 등 선 아이콘.
- `dist/browse.js`: 데스크톱의 독립 메뉴 선택 시 듣기 메뉴까지 중복 강조되던 상태 정리. 모바일 하단 메뉴의 상위 분류는 유지.
- `dist/index.html`, `scripts/build.mjs`: 파일 로드 및 배포 빌드 포함.

가사 규칙은 유지한다: 데스크톱 재생바 2줄, 모바일 웹 1줄. 솔로 녹음은 현재 줄 흰색/그 외 회색, 듀엣은 기존 3파트 색을 유지한다. 앨범 이미지, 프로필 액자, 실버/골드 선물 이미지는 변경하지 않는다.

네이티브 Android/iOS 화면은 이 CSS를 자동으로 가져오지 않는다. 네이티브 공통 테마에 위 토큰/선 아이콘/선택 상태를 이식하고 기기별로 검증해야 한다. 이번 배포는 웹 및 모바일 웹이다.

- 모바일 UI, 녹음 UI, 키 변경과 탐색 관련 기존 검사 27건 중 24건 통과.
- `tests/browse.test.mjs`의 커뮤니티 3건은 `communityLandingHTML is not defined`로 실패한다. 변경 전 소스 `a1f5e12587f31b81375a2d47ce76eb1216afe12e`에서도 동일하게 재현했다. 해당 테스트의 렌더러 로딩 누락은 이번 시각 변경과 별개다.
