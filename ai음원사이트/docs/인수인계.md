# AIFECT 인수인계

기준일: 2026-09-24

## 서비스 구성

- 공식 주소: https://aifect.co.kr
- 프런트엔드 원본: `dist/`의 HTML, JavaScript, CSS 및 `dist/assets/`
- API: `server/`, 공통 로직: `shared/`
- 데이터 구조: `db/schema.ts`, 변경 이력: `drizzle/`
- 음원 변환: `transcoder/`, 가사 자동 싱크: `alignment/`
- 정기결제 및 알림 중계: `billing/`
- Sites가 Cloudflare Worker, D1 `DB`, R2 `BUCKET`을 관리합니다.

## 실행

이 폴더에서 Node.js 22 이상을 사용합니다.

```sh
npm ci
npm run build
```

`.env.example`을 참고해 필요한 로컬 값을 `.dev.vars`에 설정합니다. 실제 비밀키는 Git에 저장하지 않습니다. 로컬 DB를 준비한 뒤 개발 서버를 실행합니다.

```sh
npx wrangler d1 migrations apply DB --local
npm run dev
```

개발 서버 주소는 `http://127.0.0.1:4174`입니다. 전체 테스트는 `npm test`이며 `tests/api.test.mjs`는 개발 서버와 로컬 테스트 설정이 필요합니다. 해당 통합 테스트는 로컬 전용 토큰 `local-transcoder-test`를 사용합니다. 운영 서버를 테스트 대상으로 지정하지 않습니다.

## 배포

`npm run build`는 `dist/client/`와 `dist/server/`를 생성합니다. 이 생성물은 Git에 포함하지 않습니다. 기존 `.openai/hosting.json`의 Sites 프로젝트와 D1/R2 바인딩을 유지하고 공식 Sites 배포 절차로 배포합니다. 이 저장소에 push하는 것만으로 운영 배포가 자동 실행되지는 않습니다.

서버의 각 작업 서비스는 독립된 Compose 설정을 사용합니다. 다른 서비스가 중단되지 않도록 해당 서비스만 변경하고 `--remove-orphans`는 사용하지 않습니다. DB와 업로드된 사용자 파일은 이 저장소에 포함되지 않습니다.

## 결제

Premium은 월 4,900원(부가세 포함)입니다. NICEPAY 직접 연동 코드가 있으며 `BILLING_CHECKOUT_ENABLED=false`를 유지합니다. 나이스페이 심사 접수 및 정기결제 승인 확인은 아직 남아 있습니다. 실제 카드 등록·청구 테스트도 아직 수행하지 않았습니다.

자세한 제출 기록은 [NICEPAY 제출현황](NICEPAY-제출현황.md), 운영 구조는 [billing/README.md](../billing/README.md)를 참고합니다.
