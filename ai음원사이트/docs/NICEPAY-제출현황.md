# NICEPAY 결제경로 제출현황

2026년 9월 24일 00:08(KST), 계약 담당자에게 기존 계약 안내 메일의 답장으로 결제경로 PDF 10쪽을 전송했습니다. Gmail에서 메시지 전송 완료와 첨부파일을 확인했습니다.

제출 자료: [AIFECT 카드 정기결제 경로](AIFECT_NICEPAY_payment-flow_2026-09-24.pdf)

## 제출 내용

나이스페이가 제공한 정기과금 예시 항목에 맞춰 사업자 정보, 이용약관·개인정보처리방침의 운영자 표시, 홈페이지, 로그인, 상품·가격, 카드 정보 입력 화면을 정리했습니다.

카드 입력 화면 2쪽은 동일한 배포 소스를 개발 환경에서 실행한 캡처입니다. 운영 화면과 구분해 표시했고 실제 카드 승인 내역을 포함하지 않았습니다.

## 회신을 요청한 사항

- 현재 자료로 카드사 심사를 접수할 수 있는지와 보완 항목
- 심사용 ID/PW 또는 결제창에 접근하는 별도 경로가 필요한지
- 현재 미신고 상태인 통신판매업 신고번호의 보완 시점
- 동일 상점에 카드 정기결제를 추가 설정하는 후속 절차

## 현재 상태

메일 전송 완료를 심사 접수 또는 승인 완료로 해석하지 않습니다. 담당자의 자료 검토, 카드사 심사 및 정기결제 승인 확인이 남아 있습니다. `BILLING_CHECKOUT_ENABLED=false`이며 실제 결제는 활성화하지 않았습니다.
