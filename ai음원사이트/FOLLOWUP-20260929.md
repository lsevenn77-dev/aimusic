# AIFECT 후속 개선

기존 28개 개선(v48 / Android 2.5.0)을 보존하고 사용자 추가 요청을 반영했다. Android 2.5.1, versionCode 14.

- 정산 첫 영역에 누적 스트리밍 원형 그래프와 실제 받은 골드·유효 재생 수를 표시한다. 월별 예상 수익은 다음 달 5일 한국 시간 0시부터 공개하고 10일 정산으로 안내한다. 이미 발급된 정산 명세는 보존한다.
- 왼쪽 메뉴의 창작자를 팔로우로 바꾸고 실제 팔로우 목록을 조회한다. 버튼과 숫자는 즉시 반영하고 서버 저장 실패 시 되돌린다. 전체 보관함 재조회를 제거하고 프로필·보관함·곡 상세의 독립된 조회를 병렬 처리한다.
- 프로필 선물하기 옆에 DM 보내기를 배치했다. DM 목록은 상대별 사진·최근 메시지·날짜·미확인 개수를 표시한다.
- 크루 대화는 저장된 이전 기록을 새 멤버도 읽을 수 있다. 100개씩 이전/이후 대화를 조회하고 클라이언트에서 합쳐 기존 대화를 유지한다. 전송 요청 ID로 재시도 중복을 방지한다.
- 가입·퇴장·직책 변경·강퇴를 시스템 메시지로 기록한다. 크루장만 부크루장·운영자·매니저·크루원 직책을 지정하거나 강퇴할 수 있다. 강퇴한 계정의 재가입을 막고 기존 대화는 보존한다. 마지막 멤버가 탈퇴하면 기존 정책대로 크루와 대화를 삭제한다.
- 공개곡 한 곡은 1 XP, 받은 유료 선물은 1골드당 1 XP다. 하루 첫 채팅 10 XP와 기존 레벨별 정원은 유지한다. 가입 후 활동만 보상하고 동일 곡·선물의 재가입/다른 크루 중복 보상을 막는다. 커버 선물의 XP는 실제 가창자에게, 원곡 선물은 제작자에게 귀속된다. 무료 응원별은 XP에 포함하지 않는다.
- 채팅 영역은 웹 520px(화면 높이 65% 이내), 앱 480dp로 확대했다. `코코(크루장) 안녕하세요`, `멤버) 안녕하세요`처럼 이름과 본문을 함께 표시하고 메시지 아래 시간을 제거했다. 웹 Enter 전송·Shift+Enter 줄바꿈·한글 IME 조합 보호, 앱 키보드 보내기를 지원한다.
- 커뮤니티 미가입자는 크루 둘러보기와 검색·만들기를, 가입자는 내 크루 들어가기를 이용한다. 가입자에게 만들기 버튼을 숨긴다.
- 노래방 차트는 공개 커버곡만 표시하며 좋아요가 없는 새 커버도 포함한다. 비어 있으면 `아직 등록된 커버곡이 없어요`를 표시한다. 부르기에서 선택하는 원곡/MR 목록은 유지한다.
- AI 가수를 선택한 원곡의 목록·상세·피드 기본 이름은 AI 가수만 표시한다. 커버는 실제 가창자를 표시하고 서버 소유권·정산 연결은 유지한다.
- 선물함 버튼과 카드·제목 사이 간격을 정리했다. 로고 아래 문구는 이전 4번 요청에 따라 숨긴 상태를 유지한다.

검증: 서버 테스트 162개, 앱 기기 테스트 21개, JVM 테스트 19개, Android lint 오류 0개(기존 경고 64개). 데스크톱/390px 웹 브라우저에서 가입 상태, 채팅 저장·직책, Enter/IME, DM 분리, 팔로우 지연·실패 복구, 정산·차트 빈 상태, 선물 간격을 확인했다. 팔로우 UI 응답은 로컬 테스트에서 49ms였으며 운영 네트워크 응답시간 보장은 아니다. 휴대폰 크기·글자 130%에서 크루/DM과 메뉴를 추가 확인했다.

앱의 실제 마이크·이어폰·블루투스 청음과 Play Console 업로드는 이번 검증 범위에 포함되지 않았다. 기존 APK 설치 서명과 Play 업로드 키를 보존하여 새 APK/AAB를 생성한다.
