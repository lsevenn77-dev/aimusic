# 2026-09-30 룸 세밀 조절 및 내 계정 로그아웃

룸 눈금을 0~100%, 1% 간격으로 변경했다. 새 100%의 wet gain은 이전 값 50%(0.5)이며, 새 10%는 이전 값 5%(0.05)이다.
앱과 웹에 동일한 룸 반사 계산을 적용한다. 원음은 그대로 통과시키고, 잔향에만 12ms 사전 지연과 140Hz/5.5kHz 필터를 적용해 저음 울림과 날카로운 잔향을 줄인다.
웹의 임의 잡음 임펄스와 자동 정규화를 제거했다. 따라서 기존 웹 룸과 음색 및 체감 크기는 달라질 수 있다.
에코 설정 범위는 기존대로 유지한다.

웹에서 녹음 전·녹음 중에도 룸을 조절할 수 있다. 실시간 듣기, 다시 듣기, 파일 내보내기에 동일한 룸 응답을 사용한다.
룸/에코/음량 변경은 오디오 파라미터를 부드럽게 바꾸므로 재생을 다시 시작하지 않는다.
드라이 녹음은 변경하지 않으며, 기존 임시저장의 룸 값은 새 눈금으로 한 번만 변환한다. 기존 50% 초과 설정은 새 최대 100%로 제한한다.

내 계정(#profile) 상단에 계정·이용권 링크와 로그아웃 버튼을 추가했다. 기존 서버 로그아웃 경로를 사용하며 프로필 저장과 독립된 버튼이다.

검증:
- 웹 자동 검사 175개 통과, 빌드 성공.
- Chrome 가상 마이크: 녹음 중 룸 변경, 다시 듣기 무재시작, 원본 보존, 내보내기, 임시저장 복원 및 한 번만 변환 확인.
- 내보낸 PCM의 새 10%/100% 잔향 RMS 비율 약 0.0978(16비트 양자화 포함), 원음 첫 샘플 동일.
- 모바일 390px에서 룸 및 로그아웃 화면 넘침 없음.
- 로그아웃 후 /api/me 비로그인 및 이전 세션 쿠키로 프로필 접근 401 확인. 운영 사용자 계정은 사용하지 않았다.
- 실제 유선/USB 이어폰에서 음색과 물리적 왕복 지연은 확인하지 않았다.
