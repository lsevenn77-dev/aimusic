# 2026-09-30 메뉴와 모바일 재생바

오늘의 응원별, 정산, DM 메시지 메뉴에 기존 선형 아이콘 스타일을 추가했다.
모바일 재생바의 곡 정보와 좋아요·선물·담기·부르기·댓글 버튼을 다른 줄에 배치했다.
재생목록은 좁은 화면에서 아이콘으로 표시하며 접근성 이름을 유지한다.
재생바 실제 높이에 맞춰 본문 하단 여백을 갱신하고 안전 영역을 포함한다.
320px 화면에서 홈의 기분 링크가 화면을 넘는 문제도 수정했다.
오디오 광고 재생 중 곡 관련 버튼은 숨김 상태를 유지한다.

검증: npm test 172개 통과, npm run build 성공.
Chrome 로컬 QA: 320/360/390/430/600/800/1024/1440px에서 버튼 겹침 및 수평 넘침 없음.
긴 제목, 가수 이름, 재생/일시정지/재개/재생목록/닫기, 메뉴 아이콘 3개 확인.
웹 녹음 엔진과 기존 대화·정산 기능은 이번 변경 범위에 포함되지 않는다.
