# AIFECT AI 음악 사이트

AIFECT의 웹사이트 소스는 [ai음원사이트](ai음원사이트/) 폴더에 있습니다.
안드로이드 · iOS 앱(Capacitor)은 [app](app/) 폴더에 있습니다.

- 서비스: https://aifect.co.kr
- [실행 및 개발 안내](ai음원사이트/README.md)
- [프로젝트 인수인계](ai음원사이트/docs/인수인계.md)
- [NICEPAY 제출현황](ai음원사이트/docs/NICEPAY-제출현황.md)

실행 명령은 `ai음원사이트` 폴더에서 사용합니다. 비밀키, 로컬 DB, 실제 사용자 업로드 파일은 저장소에 포함하지 않습니다. 이 저장소의 push와 운영 사이트 배포는 별도입니다.
