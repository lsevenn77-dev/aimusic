# 더빙 BGM 연출 변경

사용자 청취 피드백: 효과음은 유지하되 사극의 피아노·현대적인 배경 음색을 제거하고, 일반 BGM은 도입과 절정 한 번씩 사용한다. 무도회처럼 실제 장면에서 흐르는 음악은 대사 중에도 유지할 수 있다.

- 작가와 유료 음향감독의 공통 지시에서 상시 감정 음악/보편적인 슬픈 피아노 권장을 제거했다. 첫 대사 전 도입, 실제 절정에만 한 번, 장면 속 음악은 `musicUse: diegetic`으로 구분한다.
- 새 음향 타임라인은 도입을 기존 2초 시작 여유 안에서 첫 대사 전에 끝낸다. 절정은 최대 15초 한 번이며, 전환/마무리/용도 없는 일반 대화 BGM은 새 제작에서 제외한다. 장면 속 음악은 지정한 대사 구간 동안 유지한다.
- 사극은 한국 전통 악기를 지시하고, Pika 호출에서도 가야금·거문고·대금·해금과 피아노·전자악기·현대 드럼·서양 오케스트라 패드 제외 지시를 전달한다. 오래된 피아노/신스 프롬프트도 새 호출 시 전통 악기로 치환한다. 생성 모델의 실제 음색 준수는 별도 청취 검증이 필요하다.
- SFX/환경음은 원래 위치·볼륨을 보존한다. 대사 시계와 기존 `dubbingTimeline` 재생 계약은 그대로이며, 완료된 파일이나 기존 과금 작업을 재작성하지 않는다. 합성 서버 변경 및 DB migration은 없다.
- 제작 확인창과 안내 문구도 같은 원칙을 설명한다.

검증: 도입 종료·중복 도입/절정 제거·장면 속 음악의 대사 중 지속·레거시 재생 보존·사극 지시 전달·SFX 보존을 로컬 테스트로 확인한다. 유료 Pika 재생성은 이 수정 검증에 포함하지 않는다. 사용자가 이미 들은 이전 검증 작품은 변경되지 않는다.
