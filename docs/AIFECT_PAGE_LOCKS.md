# AIFECT 확정 화면·용어·삭제 항목 보호 목록

> 이 파일은 **확정된 사용자 선택을 다시 되돌리지 않기 위한 변경 금지 목록**. 새로운 요청이 해당 항목의 변경을 명시한 경우에만 그 요청 범위에서 갱신한다. 추정한 것과 확인된 것을 섞지 않는다.

## 네비게이션
- PC 사이드바의 **기존 메뉴 전체 순서·위치·크기·간격·색상·다른 아이콘·활성 상태** 유지. 옛 메뉴 `듣기→홈`(집 아이콘), `부르기→플레이`(삼각형), `창작자 스튜디오→스튜디오`; 다른 화면으로 링크/라우팅을 임의 변경하지 않는다.
- 모바일 하단 5개: `홈 / 커뮤니티 / 플레이 / 메시지 / 마이`. 배치 변경 금지.
- 홈은 제작곡·원곡 중심; 곡 이야기에서 연관 커버·참여곡 확인. PLAY의 완성 작품은 `둘러보기`에 모은다.

## 커뮤니티
- 상위 탭은 `토킹룸 / 크루 / 랭킹`. 기본 토킹룸. 커뮤니티에 팔로잉 작품 탭을 다시 추가하지 않는다.
- 토킹룸 목록은 공개방만; PC 썸네일 카드, 모바일 2열. 미리드러나는 참여 신청 버튼 없음. 방장 승인 후 마이크 착석, 음성 좌석 최대 8개. 방 배경은 기본 3종 / 유료 상품은 선물함. 방 만들기와 이후 설정에 같은 필드 사용(이름·공개·정원·테마·공지).
- 크루는 **대문사진 없음**, 대표사진 1개. 크루장/부크루장/매니저/크루원 권한. 크루명 변경 후 30일 잠금. 현재 크루원의 공개 완료 솔로·듀엣·더빙 작품 최신순, 제목 왼쪽 유형 아이콘.
- 랭킹 하위: `작품 / AI 아티스트 / 관계 / 크루`. 작품은 `솔로/듀엣/더빙`. AI 아티스트는 원곡·제작곡만, 아티스트 고유 ID로 집계. 관계는 양측 공개 동의. 랭킹 주간 기본·월간 선택. 골드/실버 반영은 기존 합의된 초기 기획값, 확정 실서비스 점수 검증 필요.

## 선물함/선물하기
- 사이트에 이미 등록된 실버·골드 선물 **실제 이미지·가격·정렬 데이터 그대로 재사용**. 임의 가격/이미지 사용 금지.
- 중앙 카테고리는 `선물 / 테두리 / 테마 / 인벤토리`.
- 모바일 선물 팝업은 고정 높이 소형 바텀시트. **드래그 핸들 없이** 선물 카드 5열, 목록 뷰포트 약 2행, **목록 영역만** 세로 스크롤 및 가는 스크롤바. 실버/골드는 별도 큰 구획이 아니라 가치/기존 상품 순서에 맞춰 연속 노출(정확한 정렬은 기존 정책 확인).
- 이미지 선택 → 그 아래에서 `1,3,5,7,10,15,20,25...` 수량 드롭다운 → 선물하기 버튼을 누르면 그때만 차감/발송. 선택만으로 전송 금지.
- 하단 고정 **3열 × 2행**: 1열 `골드 잔액 / 실버 잔액`, 2열 `충전하기 / 오늘의 실버받기`, 3열 `수량 선택 / 선물하기`. 모바일에서도 모두 보이게 하되 텍스트 밀도 조정. 시안뿐 아니라 실제 주문·인벤토리 로직 정확성 보존.
- 입장 이펙트·채팅 이펙트 상품 없음. 이모티콘 유료 등록 기획은 보류.

## 마이페이지 / 프로필 (복구 금지 항목)
- `나의 순간들`의 `사진 올리기(+)` 카드, `소속 아티스트`의 `새 아티스트(+)` 카드 **재생성 금지**.
- 섹션 제목 앞 꾸밈 아이콘(`나의 순간들`, `내 제작곡`, `커버·듀엣·더빙`, `소속 아티스트`, `스튜디오`, `참여 가능한 듀엣`, `참여 가능한 더빙`) 복원 금지.
- 프로필 사진에 겹치는 보라색 P 원형 배지, 닉네임 옆 편집 아이콘, `(Zero)` 꼬리표, 스튜디오 버튼 앞 톱니바퀴 아이콘 복원 금지.
- 닉네임 `Veil`; 크루 `ZERO`는 크루 행에만 표시. 내 작품/내 활동 세그먼트 탭을 이동해도 상단 프로필과 나의 순간들은 동일하게 유지.
- 승인된 프로필 팝업: PC 작은 중앙 모달, 모바일 컴팩트 바텀시트, 상단 긴 드래그 바 없음. 메인 버튼은 기존 사이트와 같은 라벤더→민트 그라데이션, 보조 버튼 어두운 면/얇은 선. 프로필 팝업 외 화면까지 임의 변경하지 않는다.

## 시안과 실제 구현의 관계
- 이전에 생성된 ChatGPT 콘셉트 이미지는 비주얼 아이디어이지 운영 CSS/컴포넌트의 원본이 아니다. 실제 서비스 소스와 사용자가 최종 승인한 스크린샷이 충돌하면 우선순위 확인. 임의로 합성하지 않는다.


## 등록 시 범위 해석 (2026-10-23)

- 보호 목록은 향후 작업의 회귀 방지 기준이며, 현재 구현되지 않은 항목을 자동 구현하라는 명령이 아닙니다.
- 관계 랭킹/유료 테마는 이번 대화에서 별도 구현 없음, 준비 중 표시로 합의했습니다. 기존 합의를 우선합니다.
- 특정 프로필 이름/크루 사례는 해당 화면에 한정됩니다. 전체 사용자에게 Veil/ZERO를 하드코딩하지 않습니다.
- 운영 홈은 홈 메뉴, 현재 로컬 작업본은 듣기 메뉴입니다. 운영 기준을 문서화했으며 이번 문서 등록은 런타임 변경을 포함하지 않습니다.
