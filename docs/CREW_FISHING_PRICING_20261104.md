## 확정 규칙

최신 사용자 지시: 기존 물고기 체계는 유지하고, 높은 평가액에 어울리는 희귀 변종·고대종 이름으로 변경한다.
돛새치는 **대왕돛새치**, 철갑상어는 **고대금빛철갑상어**로 반영한다.
기존 27종의 식별자·이미지·등급·표준 길이·출현 확률·어획 기록은 그대로 유지한다.

B 크기 기준 레어는 20만~80만원(평균 50만원), 유니크는 130만~400만원(평균 250만원),
전설은 1,500만~3,500만원(평균 2,500만원), 신화는 2억5천만원이다.
레어→유니크→전설→신화의 평균 배수 5 / 10 / 10은 유지한다.
**일반→레어 5배는 이번 가격대 요청으로 대체한다.** 일반 가격은 v521과 동일하다.
이는 창작 어종의 게임 평가액이며 현실 시세라고 주장하지 않는다.

크기 보정 S 120%, A 110%, B 100%, C 90%, D 80%를 유지한다.
모든 크기를 포함해 레어 16만~96만원, 유니크 104만~480만원, 전설 1,200만~4,200만원,
신화 2억~3억원이며 등급 간 가격 역전이 없다. 유니크는 요청한 100만~500만원 안에 들어간다.

## 서버 적용과 기록 보존

- `dist/crew-fishing/pricing.js`가 단일 가격표이다. 공식/연습 새 뽑기, 잡은 결과,
  개인·크루 주간 평가액과 순위가 같은 가격표를 쓴다.
- `server/crew-fishing-pricing.js`는 같은 가격표에서 SQL 평가식을 만든다.
  기존 어획 기록도 조회 시 어종·크기 등급으로 재평가한다. 저장된 `amount` 원본은
  갱신하지 않으며, 알 수 없는 어종이나 크기 등급은 원래 금액을 보존한다.
- 현재 진행 중인 공식 낚시도 완료 시 같은 평가액을 받는다. 이미 열려 있는 연습
  세션은 다음 서버 뽑기부터 새 가격을 받으며 이전 로컬 연습 합계는 소급 갱신하지 않는다.
- 기존 주간 랭킹은 새 평가액 합계로 정렬된다. 도감의 길이 기록·획득 수·입질 확률·
  크기 확률·낚시 횟수·터치 판정·애니메이션·다른 게임은 변경하지 않는다.
- 운영 DB migration이나 기존 행의 일괄 갱신·삭제는 없다. 클라이언트가 보내는
  금액/어종/등급은 공식 평가액을 바꿀 수 없다.

## 검증

- 27종 × 5개 크기 등급: 새 뽑기/결과 함수/랭킹 SQL의 평가액 일치.
- 모든 등급 안 어종별 가격 구분, 상위 평균 배수 5/10/10, S/A/B/C/D 보정 유지.
- 유니크 전체 크기 100만~500만원, 등급 간 가격 비역전.
- 기존 금액이 큰 멸치보다 새 평가액이 큰 농어가 위에 정렬됨.
- 개인·크루 150억원 합계의 32비트 정수 초과 처리, 저장 amount 원본 보존.
- 공식/연습 뽑기에서 클라이언트 조작 금액 무시, 연습은 공식 기록에 미반영.
