# 대본 단계의 상세 음향 연출

사용자 기준은 50G(사용자가 말한 약 500원)의 가치가 소리 개수가 아니라 장면에 필요한 디테일과 정확한 타이밍에서 나와야 한다는 것이다. 공포 테스트의 노크 보정본은 사용자가 괜찮다고 확인했다. BGM 음량은 적당하므로 이번 변경에서 낮추지 않는다.

작가와 음향감독이 공통으로 사용하는 지시에 다음을 추가했다.

- 장면의 원인·행동·인물 반응을 소리와 연결한다. 재질·거리·횟수·간격·전/중/후 위치·끝나는 순간을 구체적으로 묘사한다.
- 소리를 들었다는 반응 대사보다 해당 소리가 먼저 들리게 한다. `before`, `after`, `start`, `offsetSeconds`를 인과관계에 맞게 고른다. 대사 중간의 정확한 시점이 필요하면 짧은 대사로 나눈다.
- 기다리는 정적과 마지막 여운을 대본의 `gapSeconds`에 미리 포함한다. 기존 음향 제작 단계에서는 대사 시계를 바꾸지 않는다.
- 장르와 사건에 맞는 경우 마지막 소리를 설계한다. 공포라고 무조건 귀신/비명을 넣지 않는다. 비언어적 숨·신음·기척을 사용할 때도 존재와 원인을 장면에 설정한다. 특정 성우의 목소리 복제와는 구분한다.
- 효과음의 전체 타격·간격·잔향이 실제 재생 구간 안에 완결되게 요청한다. 새 효과음 요청은 재생 길이를 올림한 초수만 생성하도록 한다. 환경음/BGM의 길이·BGM 음량 규칙은 유지한다.
- Pika 효과음 프롬프트도 정확한 횟수, 구간 내 완결, 반복 루프 금지, 요청한 비언어적 효과 허용을 명시한다.

DB/합성 서버/기존 완료 파일 변경은 없다. 이미 생성한 노크 비교본의 파일 교체나 무료 재생성을 이 변경이 자동 실행하지 않는다. 실제 생성 모델의 의미·횟수·감정·공간감 준수는 청취 검증이 필요하며 지시만으로 품질을 보장할 수는 없다. 이번 검증은 로컬 mock이며 실제 유료 API를 호출하지 않는다.
