# AIFECT 크루 주간 경쟁 게임 — Sites 적용 인수인계 (2026-11-09)

## 결정된 요구사항
- 매주 월요일 00:00:00 Asia/Seoul에 네 게임 중 **전 크루 공통으로 한 게임만** 무작위 선정하여 해당 주 시즌을 시작한다.
- 월~금에는 크루 화면에 선택된 게임의 가로 배너 1개(3:1)를 표시한다.
- 토요일 00:00부터 월요일 00:00 전까지는 배너뿐 아니라 배너를 감싼 레이아웃 항목/여백도 렌더링하지 않는다.
- 다른 크루의 게임도 같은 주에는 같은 게임을 사용한다. 접속할 때마다 다시 뽑지 않는다.
- 게임 내부 ID와 경로는 그대로 유지한다: jump, fishing, rhythm, racing.
- 웹/앱 표시명만 변경한다:
  - jump: 점프러시 (기존 점프게임)
  - fishing: 월척헌터 (기존 낚시게임)
  - rhythm: 비트콤보 (기존 리듬게임)
  - racing: 터보레이스 (기존 레이싱게임)
- 문구는 '이번 주 크루 경쟁 게임'으로 통일하고 '추천 게임', '클랜게임'은 쓰지 않는다.
- 기존 크루 정보, XP, 작품, 게임 엔진, 점수 기록 및 보상 처리는 변경하지 않는다. 기존 시즌 정산 규칙 확인 없이 점수를 초기화하거나 보상을 지급하지 않는다.

## 서버 — 반드시 시즌 선정의 단일 원천
1. 이미 주간 시즌 저장소가 있다면 재사용한다. 불필요한 중복 시즌 테이블을 추가하지 않는다.
2. Asia/Seoul의 월요일 날짜 (예: 2026-11-09)를 week_start로 사용한다.
3. 각 주에 대한 첫 시즌 생성 시 안전한 서버 난수로 4개 ID 중 하나를 선정하고 영속화한다. DB/저장소 수준 원자적 생성/읽기 또는 고유 키로 중복 생성을 막는다.
4. 재시작, 여러 서버 인스턴스, 크루별 접속, 모바일/PC 접속에서도 동일한 week_start에는 동일한 game_id를 반환한다.
5. 모든 크루의 GET /api/crews/:crew/games 응답에 현재 주의 week_start와 active_game_id를 포함한다. 클라이언트는 서버 선택을 우선한다.
6. 월요일 00:00을 정확히 넘기는 요청에서도 새 선택이 조회되어야 한다. 별도 cron만 신뢰하지 말고 멱등적인 시즌 보장을 구현한다.
7. 토·일요일에는 시즌 배너 상태를 비활성으로 반환하고 웹 UI 항목을 렌더링하지 않는다.

### 앱 호환 응답 예시 (평일)
{
  "week_start": "2026-11-09",
  "active_game_id": "fishing",
  "games": [
    {"id":"jump","title":"점프러시","route":"game/jump/<crewId>"},
    {"id":"fishing","title":"월척헌터","route":"game/fishing/<crewId>"},
    {"id":"rhythm","title":"비트콤보","route":"game/rhythm/<crewId>"},
    {"id":"racing","title":"터보레이스","route":"game/racing/<crewId>"}
  ]
}
주말에는 active_game_id=null 또는 별도 'break' 상태로 표현한다. games 카탈로그 자체는 유지해도 된다.

## 웹 — 화면 및 명칭 변경
- 크루 상세 PC와 모바일에서 기존 4개 게임 버튼을 제거하고 이번 주 선택 배너 하나로 대체한다.
- 월~금만 배너 표시, 토·일요일에는 제목·배너·패딩·마진과 사용하지 않는 컨테이너까지 제거한다.
- 게임 선택은 서버 응답의 active_game_id만 사용한다. 클라이언트 Math.random()과 접속 시 랜덤 금지.
- 기존 게임 페이지(헤더, 시작 버튼, 결과, 랭킹 등)의 옛 한국어 명칭을 네 개 새 이름으로 변경한다.
- 게임 경로 URL 및 엔진 ID는 그대로 둔다.
- 배너 원본은 Android res/drawable-nodpi/crew_weekly_*.webp 및 대화에서 확정한 4종 이미지에 있다. 웹 자산 경로에 복사해 최적화하고 클릭 시 기존 해당 게임 경로를 연결한다.
- 모바일 가로 폭 100%, 높이 자동 비율 3:1, 과도한 여백 없음. PC에서는 사이트 디자인 시스템에 맞춰 최대 폭과 자연스러운 높이를 적용한다.
- 이미지는 글자가 포함된 합성 이미지이므로 alt에 '이번 주 크루 경쟁 게임: [이름]. 플레이'를 넣고 전체 배너를 키보드로도 실행 가능한 링크/버튼으로 만든다.
