# 환경음 추가 감쇠 수정

198번 이후 확인: `먹빛 속의 어명`의 빗소리는 cue volume 0.16에 대사 구간의 환경음 duck 0.3이 곱해져, 정규화 신호의 0.048배(-26.4 dB)로 재생됐다. 원음의 인지 음량이 4.8%라는 뜻은 아니다. BGM은 없었고 Pika가 완료한 개별 음향은 환경음 1개와 사건 효과음 2개였다. 원본 Pika 파일과 직접 비교하지 않았으므로 공급자 품질 문제를 단정하지 않는다.

대사 구간 감쇠를 BGM(.55)에만 적용한다. 환경음과 사건 SFX는 cue gain을 유지한다. 새 감독 지침은 환경음 gain 0.2~0.3을 요청한다. BGM과 SFX의 기존 gain은 바꾸지 않는다.

Python/FFmpeg 테스트에서 BGM/환경음/SFX 각각의 동일한 합성 신호를 사용해 대사 전·중 RMS를 비교한다. BGM만 .55배, 환경음과 SFX는 1배를 유지해야 한다.

대본 작성 단계에서도 이야기 목적에 맞는 실제 행동을 설계하고 장면/연기 지시와 SFX를 연결한다. 감정 BGM·장소 환경음·핵심 행동 효과음의 누락을 점검한다. 회상 속 사건에 소리를 붙이거나 매 대사마다 같은 소리를 반복하지 않는다.

운영 반영 시 합성기와 Sites를 함께 적용한다. DB migration은 없다. 2026-10-23 사용자가 이 수정 반영 후 새 음향을 만들어 Pika 품질을 비교하도록 요청했다. 이 요청 범위에서 후속 수정 배포와 별도 비공개 품질 테스트를 진행한다. 기존 공개 작품의 대본·녹음·오디오는 바꾸지 않는다. 품질 테스트는 Pika 원본과 최종 믹스의 길이·음량·연출 구간을 비교하고 실제 새 생성 비용을 기록한다.
