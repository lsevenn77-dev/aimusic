# 더빙 장르 이미지

기존 카드의 빈 장르 영역에 13종 전용 커버를 연결한다. 마이페이지, 프로필의 참여 가능한 작품, 플레이의 더빙 목록과 둘러보기, 기존 더빙 카드가 같은 장르 매핑을 사용한다. 두 장르인 경우 첫 번째 유효한 장르, 장르가 없는 기존 자료는 일상 이미지를 사용한다. 작품 데이터나 DB는 수정하지 않는다.

`shared/dubbing.js`의 `dubbingGenreArtwork`가 허용된 장르만 고정된 정적 경로로 매핑한다. 사용자 입력으로 이미지 URL을 만들지 않는다. `dist/assets/dubbing-genres/`에 640×640 WebP 13종을 저장했다. 총 1,232,390바이트이며 lazy loading과 명시적인 정사각형 비율을 사용한다. 기존 재생 버튼·제목·작성자·공개 범위·라우팅은 유지한다.

내장 image_gen으로 각 장르를 개별 생성했다. 공통 프롬프트는 글자·로고·UI·테두리 없는 정사각형의 영화적인 디지털 일러스트, 작은 썸네일에서 읽히는 중앙 구도, 자연스러운 색채와 절제된 대비다. 장르별 장면은 SF 달 관측소 / 이세계물 다른 세계의 문 / 판타지 숲과 성 / 사극 조선 궁궐 / 로맨스 우산 속 두 사람 / 액션 옥상 달리기 / 코미디 무대 소품 / 첩보 밤 기차역 / 공포 빈 저택 / 스릴러 붉은 경고등 계단 / 미스터리 편지와 열쇠 / 일상 카페 / 감동 바닷가 벤치다.

검증: 기존 SQLite fixture의 실제 앱에서 마이와 더빙 목록을 확인했다. PC 1440×900, 모바일 390×844 및 320·768px에서 가로 넘침이 없다. 썸네일 로딩·정사각 비율·object-fit과 기존 작품 링크를 확인했다. 운영 DB를 사용한 시각 변경은 하지 않았다. 배포는 저장한 후보에 대한 사용자 승인 후 진행한다.
