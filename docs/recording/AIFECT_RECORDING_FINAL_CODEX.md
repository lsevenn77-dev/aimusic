# AIFECT 녹음 페이지 UI/UX 최종 통합 작업지시서 — 2026-10-28

**대상:** `https://aifect.co.kr/#sing/d4c239cc-d765-4ca3-a62e-97283a7c9e8b` 및 동일한 녹음 화면 컴포넌트를 사용하는 **모든 솔로·듀엣 진입 경로**.
**목적:** 실제 기능을 100% 보존한 채 PC/모바일의 레이아웃·상태 표시·상호작용·디자인을 일관되게 최적화한다. **코드 수정, 테스트, 결과 보고까지 수행하되 운영 배포는 하지 않는다.**

## 0. 반드시 먼저 할 일: 실제 코드 조사와 기존 기능 보전

1. 루트 및 관련 경로의 `AGENTS.md`를 반드시 확인하고 준수한다. 프로젝트의 스타일 토큰·공통 컴포넌트·라우트·모바일 웹뷰 코드도 읽는다. **파일명과 구현 상태를 추측하지 않는다.**
2. `#sing`의 솔로/듀엣 진입, 가사 렌더링·싱크, 오디오/녹음 엔진, 소절 선택·이전 소절 프리롤, 파트 분배 팝업, 실제 설정 UI·값, 미리듣기/완료·저장/초안/공개를 찾고 현재 동작을 먼저 기록한다.
3. **기능의 기준은 현행 작동하는 코드와 `references/02_actual_settings.png`**이고, 시각적 기준은 `references/03_site_style.png`, `references/01_fixed_settings_icon.png`, 합의된 레이아웃 설명, `references/04_latest_layout_reference.png` 순이다. *AI 이미지에 그려진 가짜 기능·잘못된 색/아이콘은 적용 금지.* 지시서 텍스트가 시안 이미지와 충돌하면 **이 문서가 우선**이다.
4. 작업 스코프는 녹음 UI 관련 컴포넌트/스타일/필요 최소한의 이벤트 연결. **WebAudio·MediaRecorder·오디오 합성/동기화·기존 녹음 API·사용자 데이터·권한·듀엣 데이터·정산/구독 정책을 리팩터링하거나 교체·삭제하지 않는다.** 새 음악 서비스 기능은 발명하지 않는다.
5. 이미 있는 정상 동작은 유지한다. 이 문서에 명시된 UX 변화(가사 탭 일시정지·소절 복귀·3점 카운트 등)는 기존 상태와 처리 흐름을 우선 재사용해 최소 수정한다. 구현 불일치·위험이 확인되면 동작을 임의 대체하지 말고 최종 보고에 명확히 남긴다.
6. 서비스 공통 사이드바·메뉴·디자인·페이지를 바꾸지 않는다. **운영 배포, DB 변경, 사용자 녹음 데이터 수정 금지.**

## 1. 최종 AIFECT 시각 디자인

- **실제 사이트 스크린샷의 분위기를 정본으로 사용:** 거의 단색에 가까운 다크 네이비, 어두운 회청색 카드, 얇은 테두리, 낮은 대비의 보조 텍스트. 현재 사이트 디자인 토큰이 우선이며 샘플 참고 배경 `#0C121B`, 사이드 `#0F1621`, 카드 `#131B26`, 입력/패널 `#1C2432`, 선택 그라데이션 `#D3BAFF → #AEE9E0`를 사용 가능. 이 값들로 사이트 전역을 덮어쓰지 않는다.
- 메인 배경의 은하수/별·광선/강한 블러·전체 네온 발광 **삭제**. 다크 네이비 단색 또는 구분이 약한 은은한 그라데이션만. 기존 페이지의 헤더/사이드바 유지.
- 그라데이션은 **중앙 녹음 버튼 링, 선택된 세그먼트, 선택한 공간 효과**처럼 소수의 상태 강조에만 적용. 모든 텍스트·카드·보조 버튼에 컬러 효과를 뿌리지 않는다.
- 모든 입력·설정 버튼은 동일한 `border-radius`, 선 두께, 타이포 스케일, 아이콘 두께·시각 크기. 영역 크기를 과대하게 늘리지 않고 **정보 밀도를 정돈**한다.
- 녹음 화면에 원래 필요 없던 **앨범 썸네일, 중복 가사 미리보기, 부가 설명 배너, 음파 장식, 가사 왼쪽의 X/체크/파트 아이콘**을 추가하지 않는다. 특히 사용자가 붉은 X로 표시한 **활성 가사 줄 왼쪽 아이콘은 완전 제거**.

## 2. PC: 넓은 가사 + 오른쪽 열린 설정 영역

- 기존 AIFECT 사이드바는 **그대로 유지**. 그 옆 나머지 공간을 `가사 작업 영역(가로폭 우선) + 오른쪽 설정 영역` 2열로. 가사 약 **60~65%**, 설정 약 **35~40%**에서 시작하되 실제 가용 폭으로 조절. 설정 너비 330~390px 정도로 시작하고 화면 크기에 적응한다.
- 상단 간결한 구성: 뒤로 / 곡명 / 재생 진행선 + 현재·전체 시간 / **실제 마이크 연결 상태** / 듀엣에서만 **파트 나누기**. 솔로/듀엣 전환 버튼 없음(진입 전 선택).
- **PC 설정은 처음부터 전개**: `오디오 설정 → 노래 설정 → 공간 효과` 순. 상단에 같은 패널 타이틀을 중복하거나 3장의 비대한 카드로 늘리지 않는다. 섹션 구분선·작은 제목·조밀한 행을 사용하여 한눈에 보이게 한다. 기존 사용자 설정 세부 항목은 필요한 경우 내부 펼침.
- 오른쪽 패널 내부 컨트롤 **공통 정렬 그리드**: 왼쪽 레이블 열(예 86~96px), 오른쪽 컨트롤 열(flex: 1), 수치 열(예 44~52px)로 고정; 모든 행의 좌우 경계·내용 시작/끝선을 일치시킨다. `음높이`의 `− 원곡 키 +`, 그 밑 `원곡 키로 / ▶ 반주 듣기`, `가사 크기`의 `작게/보통/크게`는 **같은 컨트롤 열의 시작점과 끝점**을 사용한다. 위/아래 버튼 세트에 서로 다른 임의 폭, 큰 빈 여백, 삐뚤어진 오프셋 금지.
- 버튼 높이/길이 균형: 데스크톱 세그먼트·설정 액션은 같은 높이 약 34~38px, 인접 버튼의 폭을 균등 분배(기존 UI에 따라 조정). `원곡 키로 / ▶ 반주 듣기`는 한 행에서 같은 높이, 남는 공간을 동일하게 배분한다. 긴 설명은 버튼 안에 넣지 않고 아래 별도 설명 줄로 둔다. `가사 크기` 3분할도 동일 컨트롤 폭.
- 우측에 3섹션이 모두 들어오는 것을 목표로 하되, 낮은 모니터에서는 **설정 내부만 스크롤**하고 상단 진행 바/가사/하단 녹음 버튼은 움직이지 않는다.
- 하단 가운데 **다시 시작 / 녹음(일시정지) / 완료**. 시각 크기는 보조 약 40~46px, 중앙 약 50~54px부터 검토; 라벨은 동일 베이스라인, 버튼 간 거리 균형. 너무 큰 원형 버튼과 과장된 글로우 금지.

## 3. 모바일: 한 화면 고정 + 단일 설정 버튼

- 메인 녹음 화면에 **세로 페이지 스크롤 없이** 들어가게 설계. `100dvh`, safe-area, 상단/하단 바, Android Chrome·앱 웹뷰·iOS Safari 주소창 변동에 적응. 가사/버튼을 스크롤로 밀어 올리지 않는다. 작은 화면은 정보 재배치/가사 가시 줄 수 조정, 메인 body 스크롤 금지(설정 시트·파트 팝업 내부 스크롤은 허용).
- 상단 `뒤로 / 곡명 / 마이크 연결 상태 / 확정 설정 아이콘`, 그 밑 `진행 선 + 타임`, 듀엣일 때만 **작은 '파트 나누기' 버튼**, 가운데 **가장 넓은 가사 영역**, 가사 아래 **점 3개 전용 자리**, 하단 조작부.
- 설정 아이콘은 사용자가 확정한 **가느다란 원형 테두리 안의 세로 슬라이더 3개**(`references/01_fixed_settings_icon.png`)와 외형 같게. **톱니바퀴·다른 아이콘으로 변경 금지.** PC에서도 같은 아이콘을 쓸 수 있지만 PC 설정은 기본 열린 상태여야 한다.
- 모바일 메인에는 다른 설정 버튼 나열 금지. 단일 아이콘을 누르면 **통합 시트(오디오 / 노래 / 공간 효과)**, 탭은 한 줄의 작고 균형 잡힌 3분할. 시트 안에서 **기존 모든 설정 항목 접근 가능**. 시트만 내부 스크롤. 시트 열거나 조정해도 녹음/반주 진행 상태 임의 리셋·일시정지 금지.
- 하단 보조 버튼 시각 36~42px, 중앙 녹음 46~52px, 아이콘 18~22px, 라벨 약 10~11px, 간격 최적화. 다만 실제 터치 영역은 **최소 44×44px** 확보. 320px 폭에도 한 줄로 유지하고 하단 제스처 바와 겹치지 않게 한다.
- 버튼 명칭: `다시 시작 / 녹음 시작(또는 녹음) → 녹음 중 일시정지 / 완료`. 중앙 아이콘도 `마이크 → 일시정지`로 상태와 함께 변환. 기존 일시정지/재개/완료 확인 처리 정책 유지. **녹음 중인데 '녹음 시작'으로 남는 상태 오류 금지**.
- 마이크 상태: 화면 상단 설정 아이콘 왼쪽에 작은 **● 연결됨/끊김/권한 필요**(실제 장치 상태와 연동). 설정 시트 안에서도 마이크와 독립된 **이어폰 모니터링 ON/OFF**가 보이게 한다. 임의로 연결됨 고정 금지.

## 4. 실제 설정 기능 전수 보존(참조 사진 기준)

### 4-1 오디오 설정
- **마이크 볼륨**: 슬라이더+현재 퍼센트(사진의 100%는 예시 값, 초기값 강제 변경 금지).
- **반주 볼륨**: 슬라이더+현재 퍼센트(사진의 80%는 예시).
- **이어폰 모니터링**: ON/OFF 토글과 `내 목소리를 실시간으로 듣기` 도움말. 마이크 연결 상태와 별개의 값.
- 연결된 장치/권한 오류 표시를 실제 기존 오디오 상태에 연동.

### 4-2 노래 설정
- **음높이**: `− / 원곡 키 / +`, 현행 **−6 ~ +6 반음**, 원곡 속도 유지. **녹음 전에만 변경 가능하다는 기존 제한을 그대로 지킨다**(실시간 모니터링 요청 때문에 피치를 녹음 도중 새로 변경 가능하게 만들지 말 것).
- **원곡 키로** 버튼(원상 복귀).
- **반주 듣기** 버튼: 텍스트 그대로, 기존 실제 재생 기능 그대로. X로 표시됐던 **버튼 내부 재생 아이콘만 명확한 `▶`로 교체**, 보조 버튼 길이·높이 위 컨트롤과 정렬. `반주 듣기`는 **실제 있는 기능**이므로 삭제하지 않는다.
- 안내 `녹음 전에 -6 ~ +6 반음으로 조정하세요. 속도는 유지됩니다.` 취지 그대로 유지.
- **가사 크기**: `작게 / 보통 / 크게` 3등분 세그먼트, 위의 음높이 컨트롤 세트와 **정확히 같은 시작/끝선**. 실제 선택/저장 값 유지.

### 4-3 공간 효과
- **스튜디오 / 홀 / 노래방 / 사용자 설정** 네 가지 프리셋 전부. 실제 프로젝트에 존재하는 이름·설명·DSP 파라미터를 유지하고, 선택한 프리셋만 연한 그라데이션으로 강조.
- 효과 설명(`원음`, `또렷한 목소리와 짧고 부드러운 울림` 등)은 기존 설정값에 연동.
- **효과 강도** 슬라이더+퍼센트(50%는 예시).
- **사용자 설정** 눌러 펼쳐지는 **현행 세부 설정 전부 유지**. 목록을 추정해 삭제/대체/새 효과 생성 금지.

### 4-4 상태 적용
- 현행 시스템이 녹음/모니터링 중 변경을 허용하는 볼륨·모니터링·효과 값은 **조정 즉시 실제 들리는 소리와 숫자/토글/선택 상태에 반영**한다. 화면 수치만 바뀌고 실제 반영이 안 되는 문제를 막는다. 이미 구현된 오디오 경로만 사용하며 녹음 파일 믹싱·타이밍은 변경하지 않는다.
- 녹음 전용·녹음 후처리·허용 시점 제한 항목은 현행 제한 보존. 설정 열기/닫기·녹음 일시정지·재개에도 상태값 유실 금지.
- **'선택한 구간 미리 듣기'는 실제 없는 기능**이므로 UI·파형·새 플레이어·버튼을 절대 만들지 않는다. 오직 기존 **`반주 듣기`**와 **녹음 완료 후 기존 결과 미리듣기**만 각각 유지한다.

## 5. 가사 표시·터치·소절 재녹음

- 메인 화면 자체는 고정. 현재 소절 기준으로 가사 뷰 내부 렌더링만 전환/이동시키고 페이지·상단·녹음 버튼 위치는 고정. 줄 높이·폰트 크기는 **활성/비활성 및 모든 가사 줄에서 동일**. 크기 변경은 `작게/보통/크게`로만.
- 현재 줄 앞 **2줄 정도**가 항상 보이도록 우선하고, 현재 줄 + 이후 1~3줄을 화면 높이에 맞춰 정렬. 가사 가운데 정렬, 줄 간격 일정, 가사 선택 시에도 줄 위치 튐 금지. 줄이 화면 영역을 침범하지 않게 한다.
- 기본 재생/녹음 중 **가사 영역 터치 → 일시정지**, 일시정지 상태에서 **가사 한 줄 탭 → 해당 소절 선택**, 녹음 재개 시 기존의 **선택 소절 바로 이전 소절부터 반주가 재생**되는 흐름. 버튼·설정·슬라이더·팝업 클릭이 가사 터치 일시정지로 잘못 전달되지 않게 한다.
- 선택 소절로 도착하기 직전, 가사를 가리지 않는 **고정 슬롯**에 `● ● ●`가 보였다가 **1개씩 사라지는 3박 카운트다운**. 숫자 3/2/1 대형 팝업 없음, 점 전용 자리는 녹음 하단 버튼 바로 위에 확보하여 점 소멸 시 레이아웃 점프 없음. 기존 소절 타임라인을 기준으로 대상 소절 시작과 실제 녹음 재개를 정확히 맞춘다. 일시정지/취소/다른 소절 선택 시 타이머 이중 실행 금지.
- 기존 녹음/재녹음 파일의 이어붙이기·재시작·완료·나가기 확인·초안·발행 및 데이터 보존 동작은 **그대로**.

## 6. 솔로/듀엣 가사 색상과 파트 편집 — 최종 확정

### 솔로 가사
- **절대 핑크/민트/보라 등 파트 색을 입히지 않는다.** 모든 가사는 흰색~연회색 계열. 현재 소절만 **명도·굵기·절제된 중성 배경**으로 강조하고 색은 무채색을 유지.

### 듀엣 가사
- 각 줄에 **역할별 색을 항상 적용**. **내 파트=핑크 / 상대 파트=민트 / 함께=회색(읽기 쉬운 명도)**. 이전/현재/다음 모두 그 줄의 역할 색을 따르고 활성 줄은 동일 역할색의 명도·굵기·약한 배경으로만 강조. 현재 줄이라고 모두 민트/흰색으로 강제 덮어쓰지 않는다.
- **가사 왼쪽의 역할 배지/아이콘/체크 원/녹음 상태 X 요소 완전 삭제.** 메인 화면에는 상단 큰 파트 탭·불필요한 범례도 만들지 않는다. 색으로만 구분. 가사 크기와 정렬은 솔로와 공통.
- `파트 나누기`는 **듀엣 녹음 화면에만 작은 별도 버튼**. 팝업으로 기존 분배 기능 열기. 메인 화면에 파트 전환용 3버튼 만들지 않는다.

### 파트 나누기 팝업
- 사용자가 이전에 확정한 **'파트 버튼 먼저 선택 → 가사 줄 빠르게 터치'** 방식 그대로:
  1. 팝업 상단 `내 파트(핑크) / 상대 파트(민트) / 함께(회색)`에서 하나 선택.
  2. 아래 가사를 탭하면 해당 줄이 즉시 선택한 파트로 할당되고 **즉시 해당 색으로 반영**됨.
  3. 선택을 유지한 채 여러 줄을 연속 탭하여 빠르게 지정. 다른 파트 버튼 누르면 브러시 역할이 바뀜.
  4. 기존 적용/저장·취소·전체 해제 등이 구현되어 있다면 동작을 유지. 메인 듀엣 화면에 저장된 파트 매핑 유지.
- 팝업 가사에는 **불필요한 체크박스·선택한 구간 미리듣기·파형을 새로 만들지 않는다.** 모바일은 팝업 내부 리스트만 스크롤 가능, 상단 파트 버튼과 하단 적용 버튼은 안정적으로 접근 가능. PC 팝업은 화면 가리지 않는 적당한 크기.

## 7. 반응형 · 접근성 · 검증

- 브레이크포인트 시각 검증: PC `1440×900`, `1366×768`, `1280×800`, 중간 `1024×768`; 모바일 `320×700`, `360×800`, `390×844`, `430×932` 및 화면 축소/주소창 변화. **기존 사이드바 폭/스타일 유지.** 실제 사이트와 글꼴, 버튼/카드 톤 통일.
- 특히 **노래 설정의 버튼 좌우 끝 정렬**(음높이 / 원곡 키로·▶ 반주 듣기 / 가사 크기)이 픽셀 수준으로 일치하는지 확인. 모바일 탭 및 슬라이더도 카드 경계에 맞춰 정렬. 길이가 부족하면 텍스트 축소/행 재구성하되 잘림/겹침 없음.
- 점 카운트가 가사를 가리지 않고 버튼을 밀지 않으며, 메인 화면 스크롤이 생기지 않는지 확인. 마이크 권한 거부/연결 끊김/이어폰 모니터링 ON/OFF의 독립적 상태 표시 확인.
- 기능 검증: 솔로 녹음/일시정지/완료 및 기존 결과 미리듣기/저장; 듀엣 파트 지정→다시 진입 유지; 가사 터치·소절 선택→이전 소절 재생→점 소멸→목표 소절 재녹음; 음높이 제한·원곡 키 복원·반주 듣기·가사 크기; 마이크/반주 볼륨, 이어폰 모니터링, 4개 공간 효과, 효과 강도, 사용자 설정 세부 기능.
- 조절 컨트롤 `aria-label`, 키보드 포커스, 44px 터치 히트, 색상 대비, reduced-motion, 모바일 브라우저 확대/키보드로 화면 왜곡되지 않음을 확인.
- `lint` / `typecheck` / `test` / `build` 중 실제 프로젝트에서 가능한 명령 실행. 브라우저 캡처가 가능하면 PC와 모바일 *변경 전/후* 비교 캡처. 오디오 권한·실기기 테스트 불가 항목은 성공이라고 단정하지 말고 '미검증'과 수동 테스트 절차 명시.

4. PC/모바일 화면 캡처 경로(가능 시)와 레이아웃/정렬 개선 결과.
