# AIFECT 상품 제작 레이아웃

템플릿을 제작 캔버스 위에 참조 레이어로 얹고 구도를 확인합니다. 납품 ZIP에는 상품 이미지와 효과만 넣습니다.

## 방 콘텐츠 영역

| 템플릿 접두어 | 뷰포트 | 방 배경이 실제 표시되는 영역 |
|---|---|---|
| `pc` | 1440×900 · DPR 1 | 1189.2×812 CSS px |
| `pc-125` | 1152×720 · DPR 1.25 | 901.2×632 CSS px |
| `mobile` | 390×844 · DPR 3 | 390×788 CSS px |
| `mobile-landscape` | 844×390 · DPR 3 | 615.2×302 CSS px |
| `android-webview-sim` | 412×915 · DPR 2.625 | 412×859 CSS px, 브라우저 시뮬레이션 |
| `ios-webview-sim` | 393×852 · DPR 3 | 393×796 CSS px, 브라우저 시뮬레이션 |

`talk-dark`와 `karaoke-light`는 서비스 공통 토킹룸·노래방의 캡처에서 방 머리글, 좌석 또는 가사, 채팅 영역, 입력창, 재생 컨트롤의 실제 요소 상자를 측정했습니다. PC 125%는 1440×900 물리 크기에 해당하는 논리 뷰포트와 DPR을 적용한 Chrome 측정입니다. 좌표 원본은 `layout-measurements.json`에 있으며 SVG 원점은 방 콘텐츠 영역의 왼쪽 위입니다. Android Compose와 iOS WebView의 노치·시스템 바·실제 회전 조건은 별도의 기기 측정 항목입니다.

## 기타 항목

- `pc-talk-seated.svg`와 `mobile-talk-seated.svg`는 착석 수신 선물 예시입니다. 선물 본체는 PC 103.5×103.5, 모바일 67.1×67.1 CSS px로 관찰됐습니다. 좌석과 수신 대상에 따라 위치가 바뀝니다.
- `pc-talk.svg`와 `mobile-talk.svg`는 실제 아바타 사진과 장착 프레임 상자를 함께 표시합니다. 모바일 캡처에서는 사진 44×44, 프레임 66×66 CSS px입니다.
- `profile-frame.svg`는 512×512 투명 캔버스, 중앙 피벗과 공통 조립 배율 1.5를 적용합니다. 점선 사각형은 중앙 33–67% 투명 검사 구간입니다.
- `room-card.svg`는 1200×1200 제작 기준입니다. 등록된 상점의 정사각형 테마 이미지가 PC 111.2×111.2, 모바일 73×73 CSS px로 렌더링됐습니다. 방 카드와 대표 이미지를 한 파일에 연결할 경우 두 사용처를 함께 확인합니다.
