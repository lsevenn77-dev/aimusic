- 스튜디오의 정보 배너·통계·카드 외곽선을 줄이고 입력칸과 필요한 조작만 구분했다.

## 상대방에게 선물하기

상대방 프로필의 선물 버튼을 누르면 **보유 아이템 → 구매해서 보내기** 순서로 표시한다.

- `/api/me/gift-inventory`를 새로 조회해서 이미 구매한 아이템과 수량을 표시한다.
- 보유 아이템은 `/api/me/gift-inventory/:id/send`로 1개씩 사용한다. 실버·골드를 다시 차감하는 구매 요청은 보내지 않는다.
- 취소 시 전송하지 않으며, 오류 뒤 재시도는 같은 요청 번호를 유지한다. 성공하면 서버가 돌려준 잔여 수량을 바로 반영한다.
- 곡에서 연 선물 화면의 보유 아이템도 받는 사람의 **프로필 선물**로 전달하며 화면과 확인창에 이를 표시한다. 구매해서 곡에 직접 보내는 기존 흐름은 해당 곡의 선물 API를 사용한다.
- 작은 화면의 제목 줄바꿈과 실버·골드 바로가기 높이를 정리했다.

## 배너 · 프로필 사진 · 갤러리

- 메인 음악 배너와 ‘지금 주목할 만한 크루’는 최대 5개 항목을 가로로 넘긴다.
- 3초 대기 후 다음 카드로 부드럽게 이동한다. 마지막에서 첫 카드로도 같은 방향으로 이어진다.
- 드래그·상세 화면·백그라운드에서는 자동 이동을 멈춘다. 항목이 하나면 고정한다.
- 마이와 다른 사람의 프로필 사진을 누르면 큰 사진을 연다. 두 번 터치와 두 손가락 확대를 지원한다.
- 다른 사람 프로필 아래에 갤러리를 표시한다. 공개 사진 썸네일, 개수, 전체보기, 사진 확대를 연결했다. 서버가 반환한 공개 갤러리 데이터만 사용한다.
