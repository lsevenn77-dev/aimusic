# AIFECT 2.5.61 — 크루와 커뮤니티 랭킹

사용자가 보낸 현재 웹 크루 화면을 기준으로 네이티브 앱의 크루 목록과 커뮤니티 랭킹을 수정했다. 기존 다크 배경과 라일락–라벤더–민트 브랜드 색상을 사용한다. 커뮤니티 첫 진입은 기존 토킹룸이다.

## 변경

- 크루: 추천 크루의 사진·소개·인원·레벨, 검색과 필터, 큰 정사각형 사진의 2열 카드, 사진을 포함한 크루 랭킹으로 구성했다. 카드/목록 전환과 추천·최신·레벨·인원 정렬을 제공한다. 관심사·모집 상태·레벨·내 크루 필터를 제공한다.
- 랭킹: 종류 선택을 작품·AI 아티스트·크루·더빙 네 개의 아이콘 카드로 정리했다. 솔로/듀엣 선택 옆에 주간/월간 드롭다운을 두었다. 관계 랭킹과 숫자 점수는 표시하지 않는다.
- 작품은 곡 썸네일, AI 아티스트는 프로필 사진, 크루는 크루 사진을 표시한다. 커버 작품의 가수 프로필 사진이 없으면 원곡 앨범 표지를 사용한다. 각 행은 기존 곡·아티스트·크루 상세 화면으로 이동한다. 더빙은 현재 실제 집계가 없어 빈 상태를 표시한다.
- 순서는 서버 집계 순서를 유지한다. 실제 이전 순위 또는 변동 값이 있으면 상승·하락·NEW를 표시하고, 값이 없으면 `—`와 접근성 설명을 표시한다. 점수에서 변동 폭을 추정하거나 최초 조회를 NEW로 처리하지 않는다.

## 실제 데이터 확인

현재 사이트 버전 217(2026-10-25 갱신)을 확인했다. 사용자가 보낸 웹 크루 이미지와 실제 공개 `/community-v3.js`, `/api/community/rankings`, `/api/crews?summary=1` 응답을 기준으로 구현했다. 기존 216 소스의 집계·크루 구성도 비교했다. 웹사이트나 서버를 수정·배포하지 않았다.

현재 커뮤니티 랭킹 API에는 이전 순위/변동 필드가 없다. 따라서 실제 화면은 순위 번호와 `—`를 표시한다. 서버에서 실제 변동 값을 제공하기 전까지 상승 폭을 보여줄 수 없다. 크루 랭킹 응답에 없는 사진 버전은 크루 디렉터리 응답을 ID로 연결한다. 작품 썸네일은 화면에 보이는 곡의 상세 응답에서 보완하고 캐시를 사용한다.

크루 디렉터리 하단 랭킹은 웹과 동일하게 레벨·누적 경험치순이고, 커뮤니티의 기간별 크루 랭킹은 서버의 활동 집계순이다. 서로 다른 기준을 혼합하지 않는다. 경험치나 점수 숫자는 랭킹 행에 노출하지 않는다.
