# AIFECT 앱 2.5.68 (81)

## 변경

- 마이 갤러리의 전체보기는 현재 화면 위에 열리는 스크롤 가능한 2열 사진 팝업이다. 사진을 누르면 별도 확대 팝업을 열며, 닫으면 갤러리의 스크롤 위치를 유지한다. 사진 관리는 기존 편집 화면으로 연결한다.
- 마이·다른 회원·AI 가수의 프로필 사진과 갤러리 사진에 같은 확대 뷰어를 사용한다. 명시적인 이미지 영역, 확대/이동 제스처, 로딩 및 재시도를 제공한다. API 인증이 적용된 이미지 로더를 공유하고 계정별 메모리 키를 사용한다. 이 뷰어와 갤러리의 사진은 디스크에 캐시하지 않는다.
- 로그인 정보가 준비되면 가벼운 갤러리 API와 첫 사진들을 미리 불러온다. 마이의 전체 작품 목록 응답을 기다리지 않으며, 사진 관리 후 목록을 갱신한다.
- AI 가수 소개에 더보기/숨기기를 추가했다. 펼친 소개는 헤더 아래 전체 너비로 읽을 수 있다.
- 상점은 선물·액자·토크룸 배경으로 구분한다. 골드·실버는 선물 내부 탭이다. 꾸미기 상품/기간/가격은 기존 서버 카탈로그를 사용하고 구매 전 확인한다. 요청 ID를 유지해 재시도 중 중복 구매를 방지한다. 인벤토리의 보관 아이템을 사용한 뒤 액자를 장착하거나 방장 설정에서 유효한 토크룸 배경을 선택한다.
- 더빙 대본과 새 녹음은 자동으로 저장하지 않는다. 나갈 때 저장하고 나가기·저장 안 함·계속 작업하기를 선택한다. 저장 안 함은 이번 작업의 미저장 녹음을 삭제하고 기존에 명시적으로 저장한 녹음은 보존한다. 서버 임시 저장/제출은 기존의 별도 명시적 동작이다.
- 재진입 검증에서 발견한 배경음 준비의 ExoPlayer 스레드 오류를 수정했다. 다운로드는 IO에서, 재생기 준비는 Main에서 수행한다. 준비 시간 초과는 재시도 가능한 안내로 표시한다.
