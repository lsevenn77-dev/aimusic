# AIFECT 2.5.60 — 발견 색상 통일과 차트 정리

발견의 검색창·바로가기·기분 카드·검색 필터를 현재 모바일 웹과 앱의 다크 배경, 라일락–라벤더–민트 색상으로 맞췄다. 단색으로 채웠던 기분 카드와 장르의 임의 배경색을 없애고, 장르 사진과 읽기 쉬운 어두운 오버레이를 유지했다. 홈의 발견 미리보기도 같은 기분 카드 컴포넌트를 사용한다. 로고와 홈 섹션 순서는 유지한다.

검색 결과의 곡은 기존 두 줄 목록으로 통일했다. 검색어와 선택한 필터는 다른 홈 탭을 다녀와도 유지된다. 기존 노래방 바로가기는 실제 이동 대상에 맞춰 ‘플레이’로 표시한다.

급상승에는 서버 목록 순서대로 1, 2, 3위 순위를 표시한다. 실제 API `/api/catalog?section=tracks&chart=rising`를 확인했으며 21곡 응답에 이전 순위·변동 폭 필드가 없었다. 서버 코드의 기준은 최근 7일 유효 청취자 수다. 따라서 임의 상승 화살표는 표시하지 않는다. 인기 차트의 서버 순위·상승/하락/NEW 표시는 유지한다.

신인은 큰 정사각형 썸네일의 2열 카드다. 앨범 재생, 좋아요, 더보기의 플레이리스트·선물·댓글 기능을 유지한다. 일반 차트 행은 재생 버튼을 앨범 위에 배치해 제목/가수 두 줄 공간을 확보했다. 긴 텍스트는 한 줄 말줄임을 사용한다.
