# AIFECT 2.5.63 — 플레이·더빙·크루 랭킹

사용자가 보낸 「네온 은하수 속 AIFECT 앱 화면 3종(1).png」의 오른쪽 크루 랭킹을 참고했다. 현재 모바일 웹의 다크 배경과 라벤더–민트 그라데이션, 기존 로고를 유지했다. 변경은 네이티브 Android 앱에 반영했고 웹/운영 DB에는 쓰지 않았다.

## 반영한 화면과 동작

- 플레이의 노래·더빙·둘러보기 탭을 균등하게 배치하고, 하위 메뉴를 커뮤니티 랭킹과 같은 아이콘 카드로 정리했다. 둘러보기의 작품 유형은 선택창으로 바꿨다.
- 듀엣 참여는 56dp 썸네일, 곡명과 올린 사람, 참여 인원, 참여 버튼의 짧은 행이다. 완료된 참여곡 중 해당 모집곡을 부모로 가진 사용자 ID를 중복 없이 집계한다. 서버 목록이 100개 한도에 걸려 전체 집계를 보장할 수 없으면 ‘N명 이상’으로 표시한다. 조회 중/실패는 별도로 표시한다.
- 참여 버튼은 커버·듀엣 모드·모집 중·부모 없음·유효한 원곡·다른 사람의 곡 조건에만 붙는다. 일반 커버는 원곡을 불러와 노래하기로 연결한다.
- 솔로 모드 녹음에서는 일반 커버로만 공개한다. 듀엣 모집은 듀엣 모드에서 자신의 파트를 녹음하고 상대 파트를 남겼다는 확인 후 공개한다. 목소리를 자동 분석해서 빈 파트를 판정하는 기능은 아니다.
- 더빙 만들기는 장르/인원/길이/분위기/결말을 눌러 선택한다. 모든 선택지를 본문에 나열하지 않는다. 작성 오류와 진행 안내는 실행 버튼 가까이에 표시한다. 선택값 저장, 생성 횟수 제한, 응답 유실 복구는 유지한다.
- 더빙 스튜디오는 장르 이미지와 작품 제목, 배경 음향, 배역 카드, 녹음 버튼으로 정리했다. 배역 취소/새 더빙 시작은 배역 메뉴, 수정/모집/삭제는 작품 관리 메뉴로 이동했다. 기존 권한과 확인창, 녹음·저장 동작은 유지한다.
- 사람의 기본 프사는 라벤더–민트 실루엣으로 통일한다. 등록된 프로필 사진을 우선 사용한다. 커뮤니티 커버 랭킹은 올린 사람 프사이며, 프사가 없을 때 원곡 앨범 표지로 대체하던 동작을 제거했다.
- 크루 랭킹은 2–1–3 순서의 시상대, 가운데 큰 1위, 크루 사진, 왕관과 레벨, 실제 순위 변동을 표시한다. 내 크루가 응답 순위에 있으면 별도 요약을 보여주고 4위부터는 목록으로 이어진다. 사진 없는 크루는 별 모양 기본 엠블럼을 쓴다. 점수와 관계 랭킹은 표시하지 않는다.

## 데이터 한계와 남은 확인

실제 커뮤니티 랭킹 API에는 현재 이전 순위/변동 값이 없다. 이 경우 ‘—’를 표시한다. 점수로 변동 폭을 추정하거나 가짜 상승 수치를 만들지 않는다. 검증 화면의 ▲2/▼1 등은 테스트 데이터다.

현재 공개 듀엣 API에서 확인한 ‘별일 아닌 것처럼’(a12c93eb-4894-4109-8345-971c507febec)은 서버에 cover_mode=duet, duet_open=1로 이미 저장되어 있다. 원곡 ID는 d4c239cc-d765-4ca3-a62e-97283a7c9e8b이고, 해당 모집곡에 완료된 참여자는 조회 시점에 없었다. 사용자가 지적한 기존 일반 커버가 이 곡인지 최종 확인이 필요하다. 기존 데이터의 공개 종류를 바꾸는 API는 확인되지 않았고, 이 항목을 임의로 숨기거나 운영 데이터를 수정하지 않았다. 이번 앱 수정은 이후 잘못된 공개 선택과 잘못된 참여 버튼을 방지하지만, 이미 저장된 해당 분류를 소급 변경하지 않는다.
