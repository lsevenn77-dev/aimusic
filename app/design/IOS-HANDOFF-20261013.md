# 2026-10-13~14 네이티브 디자인 동기화

웹의 최근 개편을 Android Compose/Java와 iOS SwiftUI 화면에 적용했다. WebView로 바꾸지 않고 네이티브 UI를 유지한다. 웹의 스튜디오 배경 사진 1개를 앱에 번들했으며, 서버 API·스토어 결제·녹음 오디오 처리 계약은 유지한다.

## 이번 변경

- 최종 디자인 기준은 수정한 웹이다. 사용자가 보낸 모바일 이미지는 가독성/밀도 참고용이며, 화면 배치·헤드폰·중앙 플러스 버튼을 복제하지 않는다.
- 2.5.43에서 홈 앨범 선반을 136dp 카드로, 대표곡 표지를 88dp로 줄였다. 재생은 앨범 안에, 상세/담기는 기존 경로로 연결한다. 작은 프로필 60dp와 정보/동작을 묶은 요약 카드, 낮은 가로 랭킹을 사용한다. 큰 글자에서는 내용을 줄바꿈하거나 가로 스크롤한다.
- 부르기/커뮤니티는 웹의 `community-studio-v1.webp` 사진을 사용하고 문구는 네이티브 텍스트로 별도 렌더링한다. Android는 59KB WebP, iOS는 원본 크기를 보존한 PNG 변환본이다. 샘플을 보고 생성한 헤드폰 시안은 사용자 설명에 따라 **사용하지 않았으며**, 로컬 `output/concepts/headphones-unused.png`에만 보관했다.

- 홈의 MR 음악은 최대 6개 카드. 넓은 화면 2열, 휴대폰 1열로 앨범·제목·가수·재생·부르기·참여 커버를 묶는다. 참여 수는 API의 `covers`, 목록은 `/api/tracks/{id}/covers` 응답이다.
- 부르기에서도 같은 카드 사용. 초안은 탐색 버튼의 첫 번째 위치에 둔다.
- 커뮤니티는 작은 앨범과 그룹화한 재생/담기 동작의 그라데이션 피드로 구성한다. 추천 피드에서 같은 곡을 여러 종류의 추천 섹션으로 반복하지 않는다.
- 크루 탐색과 랭킹은 실제 레벨 내림차순, 경험치 내림차순으로 정렬한다. 제목 배경에 정적인 마이크·음파 선화를 사용한다.
- 플레이어 셔플 아이콘은 주변 버튼과 균형 잡힌 크기. 녹음 배경은 어두운 색과 은은한 상단 미러볼이며 번쩍이는 애니메이션은 없다.
- 초안에 별도 이어 편집/삭제와 확인창 추가. 현재 계정의 앱 내부 초안 폴더만 삭제하며 공개한 커버는 삭제하지 않는다. 계정 불일치와 경로 이탈을 거절한다.
- Android 검색 바로가기 가로 스크롤, 장르 타일 최소 높이, 좁은 선물창 3열을 적용했다. iOS 듣기 상단 탐색은 가로 스크롤을 지원한다.

## 추가 피드백 반영 · 최종 2.5.46 (59)

- ‘새로 올라온 목소리’의 더보기는 팝업이 아닌 화면 전환이다. 뒤로 돌아오면 원래 부르기 목록 위치를 유지한다.
- 차트 종류별 그라데이션 패널과 최신곡 배너를 추가하고, 인기곡/최신곡을 각각 구분된 카드로 표시한다. 제목과 가수 이름은 생략하지 않고 줄바꿈한다. 발견 검색은 한 줄 입력창으로 정리했다.
- ‘이번엔 내 목소리로’와 부르기 곡 카드의 장르는 둥근 태그로 줄바꿈한다. 실제 곡 소개를 표시하고, 소개가 없으면 녹음 방법 안내를 사용한다. 커뮤니티 카드도 장르를 제목 영역에서 분리했다.
- ‘음악 뒤의 사람들’은 이미지·이름·소개·프로필 링크의 위치와 카드 크기를 통일했다. 글자 크기가 커지면 이름/소개 영역도 함께 확대한다.
- 크루 소개는 대표 이미지, 실제 경험치 진행 막대와 멤버/정원 원형 그래프를 사용한다. 가상의 활동 이력이나 합계를 만들지 않는다.
- Android 크루 진입 시 멤버 확인 대기 상태를 비회원으로 처리해 성장 소개가 잠깐 보이던 문제를 수정했다. 공개 캐시는 채팅 권한으로 사용하지 않으며 최신 가입 경계 확인을 유지한다. 공개/비공개 응답 순서를 바꾼 회귀 검사도 추가했다.
- 커뮤니티 팔로잉 작성자/곡 정보/동작을 정렬했다. 크루 채팅은 메시지 탭의 해당 대화로 연결되며 뒤로가기는 메시지 목록으로 돌아온다. iOS는 `MessageRoute`와 바인딩된 메시지 NavigationStack을 사용한다.

## 승인받아 함께 포함한 기존 iPhone 수정

녹음 시작의 오디오 시계 기반 카운트다운/선택한 가사 위치 처리, 취소한 새 테이크 정리, 일반 가사의 타임스탬프 제거, 메시지 시간 표시/입력 지우기, 접을 수 있는 미니플레이어, 선물 지갑과 프로필 UI 수정을 보존했다. 사용자가 기존 미커밋 수정도 함께 Git에 올리도록 명시적으로 승인했다.

## iPhone 상태와 Mac에서 필요한 검증

이번 환경은 Windows이며 연결된 Mac/Xcode가 없어 **iOS 컴파일·테스트·아카이브는 실행하지 않았다**. 소스 변경만으로 iPhone 반영/배포 완료라고 판단하면 안 된다. `project.yml`의 현재 버전 **1.0.3 (12)**와 App Store 상태는 변경하지 않았다.

1. 이 커밋을 Mac에서 pull하고 `app/ios`에서 `xcodegen generate`. 새 `AIFECT/RedesignComponents.swift`와 `AIFECTTests/RedesignTests.swift`가 소스 폴더를 통해 포함된다.
2. `AIFECT` scheme으로 Debug 빌드 및 `AIFECTTests`, `AIFECTUITests` 실행. `RedesignTests` 7개의 레이아웃/크루 그래프·정렬/초안 삭제/메시지 라우팅 검사와 기존 `FeedbackTests`의 녹음 시작·가사 검사를 포함한다.
3. 작은 iPhone 및 큰 글자에서 긴 제목, 장르 태그, 창작자 카드 높이, 크루 소개, 초안 삭제 확인창과 접힌/펼친 재생바를 확인한다. 크루 채팅 진입 시 메시지 탭 선택·대화 표시·뒤로가기 목록 복귀, 새 목소리 더보기의 일반 화면 전환도 확인한다. 삭제는 테스트용 초안으로만 검증한다.
4. 실제 유선/USB 이어폰에서 녹음 시작 전 반주와 선택 가사 위치, 녹음 취소, 기존 초안 보존을 확인한다. 시뮬레이터 검사는 실제 음질·지연 검증을 대신하지 않는다.
5. 출시 요청이 있을 때 새 빌드 번호를 선택하고 서명 아카이브/스토어 제출을 별도로 진행한다.
