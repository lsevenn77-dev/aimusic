iOS에서 지켜야 할 연결

  • 프로필 → 메시지 → 닫기: 아래 프로필과 스크롤 위치가 남아 있어야 합니다.
  • 크루 홈 → 채팅: 대표 이미지와 최근 음악을 먼저 보여주고 채팅 링크를 둡니다. 메시지 목록 맨 위에는 내 크루를 고정합니다.
  • 좋은 커버 → 플레이리스트: 원곡 대신 실제 커버의 ID를 저장합니다.
  • 채팅 캐시 → 즉시 표시: 계정과 방별로 분리하고 새 메시지는 뒤에서 동기화합니다.
  • 가입 시점 이전 대화 제외: 과거 이력을 불러오지 않아도 채팅창은 보입니다.

녹음과 재생을 구분

  • 음악 재생: 미니 플레이어 가사는 한 줄 높이를 유지합니다.
  • 녹음: 현재 가사를 위쪽 약 35%에 놓고 다음 가사를 함께 보여줍니다.
  • 듀엣: 내 파트·파트너·함께를 같은 창에서 지정합니다. 성별로 구분하지 않습니다.
  • 녹음 후: 싱크 → 목소리·반주 → 리버브 → 저장 순서를 유지합니다.
  • 청음: 기본 100%, iOS 오디오 엔진에서 별도 구현·검증합니다.

로고 적용

홈 화면 아이콘과 시작 화면은 새 A 마크만, 내부 헤더는 AIFECT 전체 로고를 사용합니다. 앱 아이콘 배경은 #0F1117. 앱 아이콘 PNG에는 모서리 마스크를 넣지 않습니다.

제공된 AppIcon 세트로 기존 세트를 교체하고 AifectMark·AifectWordmark imageset을 추가합니다. 로고에는 단색 tint를 적용하지 않습니다.

완료 확인

320 / 390 / 430pt, 큰 글씨, 키보드, 노치·홈 인디케이터에서 확인합니다. 터치 영역은 최소 44pt. 로딩 중에도 뒤로가기는 가능해야 합니다.

현재 저장소에는 Xcode 프로젝트가 없습니다. 제공된 SwiftUI·이미지는 이식용 자료이며, iOS 앱 빌드와 설치는 해당 프로젝트에서 진행해야 합니다.
