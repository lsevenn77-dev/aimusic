# 점프러쉬 링크·의상 상점 수정 · 1.0.7(26)

## 변경

- 사용자가 빌드25에서 점프러쉬 의상 상점까지 진입한 화면을 제공했다. 이번 수정은 게임 안의 리듬게임 링크 제거와 잘리는 의상 카드에 한정한다.
- iOS 게임 WebView에서 `.jump-club .arc-game-choice`를 숨기고, 로비의 해당 grid 행도 제거한다. 다른 게임의 메뉴에는 적용하지 않는다.
- 원인은 공통 `compact-popup`의 높은 우선순위 버튼 스타일이었다. 카드가 높이 44px의 가로 flex 배치가 되어 이미지 옆에서 이름과 가격이 세로로 줄바꿈됐다.
- 상점 카드에만 자동 높이의 세로 grid를 지정한다. 의상 이미지는 `object-fit:contain`으로 전체를 표시하고 이름·가격은 이미지 아래에 둔다. 기존 이미지, 색상, 가격, 소유·구매 처리는 유지한다.
- 실버·골드 각각 3열을 유지하며 미리보기와 여백을 줄였다. 작은 화면에서는 대화상자 내부를 스크롤해 하단 의상과 동작 버튼을 확인한다.

## 검증 기록

- 실제 웹 client·Worker의 로컬 fixture를 iOS WKWebView로 실행한다. 임시 계정·크루를 사용하고 쓰기 요청을 차단해 구매·골드 차감·공식 기록 전송을 하지 않는다.
- 게임 렌더 호환성 Node 검사 8개 통과. 대기실 → 연습 → 결과 UI 검사 통과(35.557초).
- 상점 UI 검사는 리듬게임 링크 부재, 6개 카드의 폭·높이·화면 경계, 공주룩 선택·미리보기 가격, 하단 스크롤, 닫기 동작을 확인한다. 첫 검사에서 WebKit의 `aria-pressed` 요소가 Button이 아닌 Switch로 노출되는 것을 확인하고 테스트 탐색자를 수정했다.
- 최종 iPhone 12 UI 검사 통과(48.647초, `../work/ios-jump26-shop-compact-iphone12.xcresult`). 6개 의상의 이름·가격 모두 화면 안에 들어오는 것을 검사하고 [실제 화면](parity/jump26/iphone12-shop.png)을 확인했다.
- 최종 iPhone SE UI 검사 통과(37.180초, `../work/ios-jump26-shop-se-final.xcresult`). 작은 높이에서도 상점 안을 스크롤하면 [골드 의상 전체와 버튼](parity/jump26/se-shop-scrolled.png)을 볼 수 있고, 위로 돌아가 닫을 수 있다.
- 검증용 서버와 두 시뮬레이터는 종료했다.
