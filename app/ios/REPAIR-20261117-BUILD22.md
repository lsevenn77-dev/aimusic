# 홈 표지 로딩 개선 · 1.0.7(22)

## 원인과 변경

- 최신 Android 소스의 `BrowseScreens.ListenScreen`은 LazyColumn/LazyRow와 Coil 이미지 캐시를 사용한다. iOS 홈은 아래쪽 섹션까지 즉시 생성하고, 같은 URL도 표시 크기가 다르면 원본을 다시 내려받았다. 앱 종료 후 사용할 이미지 캐시도 없었다.
- 홈과 가로 목록을 LazyVStack/LazyHStack으로 전환하여 화면 근처의 이미지부터 요청한다. 추천 5곡, 고정 배너, 섹션 이동, 인기 차트 페이지 상태는 유지한다.
- 다운로드와 디코딩 작업을 분리했다. 계정·URL 단위로 원본을 한 번 받아 공유하고, 표시 크기별로 축소해 디코딩한다. 원본 메모리 캐시는 16 MiB, 디코딩 캐시는 기존 48 MiB로 제한한다.
- 앨범 표지의 실제 표시 크기·화면 배율에 맞춰 디코딩하며, 흐린 배경은 256px, 홈 아티스트 썸네일은 224px만 사용한다. 기존 추천 행의 62pt 표지는 이미 크기를 제한하고 있었다.
- 서버가 명시한 공개 이미지에만 최대 64 MiB / 512파일 디스크 캐시를 적용한다. `max-age`와 `Age`를 반영하고 최대 30일로 제한한다. 표지 URL의 버전이 바뀌면 새로 받는다. 저장·로드·정리는 메인 스레드 밖에서 수행하며 캐시 저장 실패가 표지 표시를 막지 않는다.
- 비공개·no-store·no-cache·계정별 Vary 응답과 앱 세션 쿠키를 설정하는 응답은 디스크에 저장하지 않는다. Cloudflare의 공개 이미지용 쿠키는 응답에서 허용하되 캐시 파일에는 쿠키를 기록하지 않는다. 일반 이미지 요청에서 사용하지 않는 `X-Aifect-Image-Mirror` 변형 헤더를 명시적으로 구분한다.
- 같은 출처는 기존 인증 API를 통하며 외부 카탈로그 이미지는 익명 세션을 유지한다. 계정 변경 시 이전 이미지 작업 결과를 적용하지 않는다.

## 확인

- 운영 공개 추천 표지 5개를 Mac에서 조회: 모두 HTTP 200, 약 98–309 KB, 각각 0.69–1.37초. 서버가 공개 캐시를 허용하고 있음을 확인했다. 이 측정은 iPhone의 체감 속도 측정이 아니다.
- iPhone 12 / iOS 26.2 시뮬레이터에서 단위 검사 6개와 UI 검사 3개 통과: `ios-build22-artwork-v2.xcresult`.
  - 12개 동일 크기 요청 및 다른 크기의 상세 이미지가 원본 다운로드 1회를 공유한다.
  - 8개 혼합 크기 요청도 원본 1회를 공유하며, 잘못된 이미지·HTTP 오류는 재시도할 수 있다.
  - 새 저장소·캐시 인스턴스에서 디스크 파일을 재사용한다. URL 버전 변경 시 추가 다운로드가 발생한다.
  - 공개 캐시 만료, 비공개·개인화 응답 제외, 쿠키 미저장, 계정 변경 후 재조회가 동작한다.
  - 홈 추천 5곡 배치, 하단 섹션 스크롤·아티스트 이동, 차트 좌우 넘기기·탭 복귀 후 페이지 유지가 동작한다.
- 초기 검사에서 디스크 전용 URLCache가 실제 저장하지 않는 것을 발견해 파일 캐시로 보완했다. 홈 섹션 UI 검사도 배너가 아닌 본문 스크롤을 지정하도록 수정했다. 실패한 초기 실행은 최종 통과 개수에 포함하지 않는다.
- [최종 홈 화면](parity/build22-home-artwork.png)은 테스트용 표지를 사용하는 UI fixture 화면이며 운영 콘텐츠나 실기기 속도 측정이 아니다.

## 배포 상태

- Release 아카이브 `AIFECT-1.0.7-22.xcarchive` 생성·서명 검증 성공. Info.plist의 1.0.7 / 22와 테스트 fixture 문자열이 없는 Release 바이너리를 확인했다.
- 연결된 iPhone 12에 기존 데이터를 유지하여 설치했다. `devicectl device info apps`가 `kr.co.aifect.app`, 버전 1.0.7, 빌드 22를 반환했다.
- 앱 실행은 기기의 `Locked` 오류로 차단됐다. 실기기에서 홈 표지가 표시되는 속도의 전후 비교는 아직 하지 못했으며, 잠금 해제 후 확인이 남아 있다.
- 시뮬레이터는 검사·화면 확인 후 종료했다.
- 심사 대기 중인 1.0.7(17)은 이 작업으로 교체하지 않는다. 웹·서버 배포는 필요하지 않다.
