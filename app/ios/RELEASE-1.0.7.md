# iOS 1.0.7 (17) · 2026-11-17

## 사용자 변경

- 하단 탭의 실제 터치를 기본 탭 영역이 가로채던 문제를 수정한다.
- Android 2.5.130(143), `74fbcf9` 기준 플레이·더빙 발견·메시지·마이 화면과 녹음 흐름을 반영한다.
- 한 파트씩/이어서 녹음, 입력 마이크 0~200%, 배경/목소리 미리 듣기 개별 볼륨, 대사별 로컬 보존과 화면 종료 후 제출 지속.
- 새 대본 작성은 AI·직접 작성·붙여넣기 세 가지 진입점을 제공한다. 장면/대사 카드, 화자·연기 지시·시간, 접기/복제/이동/삭제/실행 취소, SFX/BGM 블록을 같은 편집기에서 편집한다.
- 붙여넣기 분석은 무료 로컬 규칙 파서다. 원문과 미분류 항목을 보관하고 확인 후 반영하며 미분류 항목은 확인 전 서버 저장을 막는다.
- 기기 자동 저장, 편집 위치 복원, 서버 revision 충돌 시 별도 비공개 복사, AI 수정 전후 비교 및 확인 후 적용.
- AI 부분 수정은 기존 서버 작성 횟수에서 1회를 사용한다. 실패/응답 유실의 기존 복구·횟수 정책을 유지한다. 성공한 수정안을 적용하기 전에는 원문을 교체하지 않는다.
- v1 대본과 기존 배역·녹음·게시 API를 유지한다. 총 24개 음향 안에 BGM 최대 3개, 대사 120개·장면 12개·최대 5분의 기존 서버 제한을 유지한다.

## 적용 범위

이번 결과물은 iPhone 네이티브 앱과 필요한 공통 API이다. 첨부 기획의 PC 웹 및 Android 카드 편집 UI 전체를 이 변경으로 구현했다고 보지 않는다. 실시간 합동 더빙은 사용자 요청에 따라 계속 보류한다.

공통 API는 운영 Sites v791의 `5398022` 서버를 재사용한다. 요청의 `edit.mode/scene/description/lines`와 응답의 `suggestions`를 연결한다. 배역·시간·음향은 수정 결과에 포함시키지 않으며 iOS가 선택한 대사의 text만 적용한다. 구형 서버에 수정 요청을 신규 이야기 생성으로 보내지 않도록 인증된 `/api/dubbing/editor-drafts` 조회 성공을 먼저 확인한다. 새 DB migration 및 모델/API 키·과금 정책 변경 없음. 실제 유료 AI 호출은 실행하지 않고 로컬 모의 공급자로 검사한다.

• 파트별/이어서 녹음, 마이크 입력과 볼륨 조절을 개선했습니다.
• 플레이·더빙 탐색·메시지 화면과 목록 로딩을 개선했습니다.
• 하단 메뉴의 터치 동작을 안정적으로 개선했습니다.
