# iPhone 화면 밀도 및 크루 게임 재검증 · 2026-11-17

## 문제와 기준

실기기 1.0.7(17)을 설치한 사용자가 Android와 다른 화면 구성, 적은 표시량, 점프게임 실행 문제, 전환 지연을 보고했다. 사용자가 제공한 11:14 Android 홈 사진과 Android 2.5.130(143) `74fbcf9`의 실제 활성 화면(`BrowseScreens`, `CurrentExperience`, `ReferenceWorks`)을 기준으로 다시 대조했다. 이전 iOS의 카드 3개/곡 표지 배너와 현재 Android의 구분선 목록 5개/기능 홍보 배너는 동일한 디자인이 아니었다.

## 변경

- 홈: Android의 7개 기능 배너 및 기존 이미지, 2.45:1 비율, 14pt 좌우 여백, 고정 배너 아래 섹션 이동, 추천 5곡, 메타데이터/구분선/세 줄 메뉴. 주간 차트를 별도로 조회하여 10곡씩 표시한다.
- 플레이·커뮤니티: Android에 없는 추가 제목 영역을 제거하고 본문 상단 여백을 맞춘다. 더빙 탐색의 간격을 최신 Android와 맞춘다.
- 마이: 72pt 아바타와 이름 옆 편집, 프로필 안의 팔로워/팔로잉/공개곡, 선물 랭킹·스튜디오 행. 제작곡/커버·듀엣·더빙을 한 줄 3개 선반으로 표시하고 전체 보기에서 관리한다. 갤러리와 아티스트 순서를 맞춘다. 프로필 편집·ID 복사·작품 삭제·계정 설정 진입을 보존한다.
- 하단 탭: Android의 52pt 높이와 선택 표시. 터치 영역은 유지한다.
- 이미지: 중복 요청을 공유하고 썸네일을 표시 크기에 맞게 축소한다. 디코딩을 메인 스레드 밖에서 수행하며 계정별 캐시 경계를 유지한다. 변경 없는 받은 메시지 목록은 다시 발행하지 않는다. 실기기 전환 시간의 개선 비율을 측정한 것은 아니다.
- 게임 웹 화면: 로딩 진행률·재시도, HTTP/프로세스 종료 오류, JavaScript 확인창, 모바일 여백·뷰포트, 하위 프레임 정책을 보완한다. 세션 쿠키 복사가 끝난 뒤 같은 출처의 작업 화면을 연다.

## 검사 방법과 범위

iPhone 12 / iOS 26.2 시뮬레이터, 논리 화면 390×844. 외부 쓰기를 차단한 UI fixture를 사용한다. 점프는 기존의 “검증용 작업 화면” HTML을 제거하고 실제 게임 JavaScript/CSS/이미지를 로컬 서버에서 실행한다. 공식 도전·구매·기록 제출 API는 호출하지 않는다. 서버는 `app/ios/scripts/game-fixture-server.py`로 실행하며 계정 정보 대신 테스트 데이터만 제공한다.

이전 크루 UI 검사는 게임 제목/경로만 확인했으며 실제 플레이 검증을 의미하지 않는다. 이번 중간 검사에서는 홈 fixture 곡 수 기대값, 로컬 게임 core 파일 연결, 컨테이너 접근성 ID 전파, 게임이 자동 충돌하기 전에 일시정지를 눌러야 하는 검사 타이밍 문제를 발견했다. 실패한 검사를 성공으로 계산하지 않는다.

## 배포 구분

수정 대상은 1.0.7(18)이다. 이미 심사 대기 중인 1.0.7(17)은 이 로컬 변경으로 바뀌지 않는다. 아래 최종 빌드·검사·기기 설치 결과를 별도로 기록한다.

## 최종 시뮬레이터 검사

`ios-repair-build18-final.xcresult`: 단위 검사 22개, UI 시나리오 3개 모두 통과(0 실패).

- `testIPhoneHomeKeepsAndroidBannerAndSectionProportions`: 배너 비율/좌우 여백, iPhone 12 첫 화면의 추천 5행, 배너 고정 및 주간 차트 이동, 다섯 탭 터치.
- `testPrimaryScreensUseAndroidContentDensity`: 플레이·커뮤니티의 중복 제목 제거, 더빙 배너 진입, 마이 프로필 높이 및 편집 버튼.
- `testRealJumpGamePracticeOnIPhoneViewport`: 실제 게임 소스의 대기실 → 연습 시작 → 일시정지 → 계속하기 버튼 표시. 모든 게임 API 쓰기는 차단한 fixture다. 별도 중간 실행에서 충돌 후 결과 화면도 확인했다. 공식 도전과 운영 계정의 실기기 게임 실행은 이 검사로 증명되지 않는다.
- 이미지 동시 요청 12개가 한 요청으로 합쳐지고, 2048px 원본을 192px 썸네일로 축소하는 검사 및 기존 계정 전환/미디어 접근 검사를 통과했다.

직접 열어 확인한 캡처: [홈](parity/iphone12-home-fixed-promotion-build18.png), [마이](parity/iphone12-my-density-build18.png), [플레이](parity/iphone12-play-density-build18.png), [커뮤니티](parity/iphone12-community-density-build18.png), [더빙](parity/iphone12-dubbing-density-build18.png), [점프 일시정지](parity/iphone12-real-jump-paused-build18.png). 목록·계정·음원 표지는 테스트 데이터이며 운영 자료를 바꾼 것이 아니다. 홈 배너는 Android에 포함된 실제 디자인 리소스다.

검사 후 공용 웹 화면의 로딩/실패 안내 문구에서 게임 전용 표현을 제거했다. 노래방·토킹룸에도 쓰이는 공용 화면이므로 “화면/작업 화면”으로 표시한다. 기능 변경 없이 Release 컴파일에서 함께 확인한다.
