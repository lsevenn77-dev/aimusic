# iOS 1.0.8 (27) · 2026-11-17

## 교체 범위

사용자 요청에 따라 심사 대기 중이던 1.0.7(17)을 철회하고 1.0.8(27)로 교체한다. 빌드18~26에서 검증한 iOS 개선사항을 모두 포함한다. 앱 코드 변경 없이 마케팅 버전과 빌드 번호만 올렸으며, 운영 중인 1.0.6을 판매 중단하지 않는다.

## App Store 업데이트 설명

음악 감상과 창작, 커뮤니티 이용을 더 편하게 개선했습니다.

• 처음 시작하는 분을 위한 5단계 앱 소개를 추가했습니다.
• 홈의 음악 목록과 표지 로딩, 탭 전환 속도와 화면 겹침을 개선했습니다.
• 인기 차트를 옆으로 넘겨 볼 수 있고, 크루 공지·관리를 현재 화면에서 확인할 수 있습니다.
• 알림 화면을 열면 읽음 상태가 반영되며 댓글·커버 등 알림 종류를 정확히 구분합니다.
• 녹음 설정을 접고 펼칠 수 있고, 녹음을 시작하면 가사로 돌아갑니다.
• 더빙 대본의 장면·대사 편집, 자동 저장, 붙여넣기와 파트별·연속 녹음을 개선했습니다.
• 점프러쉬 진입 문제를 수정하고 의상 상점의 이미지·이름·가격을 보기 쉽게 정리했습니다.

## 검증 근거

- 각 기능의 단위·UI 검증은 `REPAIR-20261117*.md`에 기록했다.
- 최신 점프러쉬 변경: 렌더 게이트 회귀 검사 8개 통과, 실제 웹 fixture를 통한 연습 실행 통과, iPhone 12·SE 상점 UI 검사 통과. 빌드26은 실제 iPhone 12에 업데이트 설치됐다.
- 실기기 전체 기능·오디오·결제·광고 통과를 의미하지 않는다. 1.0.8은 동일 코드에 대한 배포용 버전 변경이다.
