# 탭 잔상·Android 메뉴 연결 수정 · 1.0.7(19)

기준: Android 2.5.130(143), `74fbcf9`. 해당 원격 브랜치를 다시 fetch했으며 Android 소스의 추가 차이는 없었다. 사용자에게서 “탭을 바꾸면 이전 화면이 잠깐 겹쳐 보임”이라는 재현 조건을 확인했다.

## 변경

- 선택된 탭 화면 하나만 마운트해 이전 화면의 스크롤/터치 영역과 전환 스냅샷을 제거했다. 전환 애니메이션은 끄되 화면 내부 애니메이션은 유지한다. 하단 탭/미니플레이어를 본문과 별도 배치한다. 홈 섹션·차트 페이지·커뮤니티 메뉴 선택은 상위 상태에 보관하고 홈·마이의 계정별 캐시를 재진입 첫 화면에 즉시 표시한다.
- 홈 배너의 UIKit 페이지 컨트롤이 프레임 밖의 터치를 가로채는 문제를 발견해 가로 스크롤 페이지로 교체했다. 배너 이미지·비율·자동 전환·페이지 표시를 유지한다.
- 홈 인기차트는 10곡씩 좌우 스와이프한다. 마지막 페이지의 남은 곡 수를 표시하며 탭을 왕복해도 페이지를 유지한다. 고정 홈 배너와 추천 5행은 유지한다.
- 크루 공지, 채팅, 크루 관리, 크루 찾기를 각각 전용 화면에 연결했다. 공지 읽기·권한에 따른 관리, 역할/가입일/탈퇴 제약을 Android와 대조했다. 크루 찾기는 원형 이미지·이름·멤버/레벨의 작은 행, 검색·필터·정렬, 크루 랭킹 연결로 교체했다.
- 플레이 노래 메뉴의 인기/듀엣/초안 아이콘을 추가했다. 둘러보기 메뉴에는 Android 벡터 아이콘을 사용한다. Android의 노래 “추천” 탭은 텍스트만 사용하는 구성이다.
- 메시지는 이전 제목/검색/관리 메뉴를 제거하고 Android의 전체·공지·알림 필터, 새 대화 버튼, 모두 읽음, 개별 대화 길게 눌러 삭제를 유지했다. 대화 행의 중복 여백을 제거했다.
- 마이는 사진 확대, 갤러리 목록/추가, 소속 아티스트 목록을 각각 실제 목적지로 연결했다. 작품 전체 목록은 검색/종류 필터/최신순과 표지 재생 버튼을 제공한다. 화면 너비를 관찰해 다시 레이아웃을 바꾸던 코드를 기기 너비에서 직접 계산하도록 바꿨다.
- 홈·마이는 최근 계정별 캐시를 먼저 표시하고 기존 경로별 TTL 안에서는 네트워크 요청을 반복하지 않는다. 홈 수동 새로고침은 캐시를 우회한다. 기존 GET 캐시 허용 경로에 한해 동시 요청을 하나로 합치고, 계정 변경/쓰기 시 무효화한다. 민감한 비캐시 경로와 쓰기 요청은 합치지 않는다.

## 검증 범위

테스트 계정·목록 fixture를 사용한 iPhone 12 시뮬레이터 검사다. 운영 게시물·계정·결제·랭킹에는 쓰지 않는다. 화면 전체가 Android와 완전히 동일하다는 주장이 아니며 실제 네트워크 지연 감소율은 측정하지 않았다.

중간 검사에서 차트 영역으로 이동되지 않는 문제, 메시지 필터의 접근성 식별자 중복, 마이 너비 재계산에 따른 레이아웃 정지를 발견해 수정했다. 최종 결과와 실기기 설치 상태는 아래에 기록한다.

- `work/ios-build19-verified.xcresult`: 크루 찾기/필터/랭킹, 공지·채팅·관리·찾기 분리 연결, 플레이·메시지·마이/갤러리 **3개 통과**. 이 중간 실행의 홈 2개 실패는 위 최종 홈 실행에서 수정 후 통과했으며, 중간 실행 전체를 성공으로 계산하지 않는다.
- `work/ios-build19-final.xcresult`: API 중복 요청 병합·캐시 무효화·계정 격리·경로 검증 등을 포함한 관련 단위 검사 **31개 통과**. 이후 변경은 홈/루트/마이의 화면 레이아웃에 한정했고 최종 화면 검사로 확인했다.
- QA 캡처는 `parity/20261117-build19/`에 보관한다. 가짜 계정·목록 이미지로 구성한 테스트 자료이며 스토어 스크린샷이 아니다.
- 최초 유지형 화면 스택은 UIKit 터치 영역이 남아 폐기했다. 마지막 홈 변경은 UIKit 배너 페이지 컨트롤을 제거하고 SwiftUI 가로 스크롤로 전환한 것이다. 마이의 중첩 lazy 레이아웃도 일반 스택으로 바꿔 스크롤 중 반복 레이아웃 정지를 없앴다.
- XCTest 로그의 입력 소요 시간은 테스트 전달/스냅샷/앱 대기까지 포함하므로 실제 앱 탭 전환 성능 수치로 사용하지 않는다.
