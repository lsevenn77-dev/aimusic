이전 광고 정책에서는 Google 공식 테스트 전면 광고가 감상 5곡, 커버 업로드 완료, 원곡 업로드 완료 조건에서 총 3회 표시되고 닫힌 뒤 호출 흐름으로 복귀했습니다. 빌드 4에서는 감상 시 영상 광고를 제거했으며, 아래 새 검증 결과가 현재 정책입니다. 같은 업로드 재시도와 Premium 제외도 확인했습니다. Debug 검증 화면에서 완료 콜백을 실행했으며 운영 서버에 실제 음악을 게시하지 않았습니다. 유료 동영상 광고 소재와 광고 게재 승인은 별도입니다.

로컬 구매 통합 검사는 AIFECTPaymentsTest scheme의 AIFECTPaymentTests target을 사용합니다. AIFECTTesting.storekit은 테스트 번들에만 포함됩니다. 2026-10-07 iOS 26.2 시뮬레이터에서 8개 중 7개 통과, 1개 보류, 실패 0개를 확인했습니다.

골드 환불 알림 검사는 보류입니다. 로컬 StoreKit에 환불 기록은 생겼으나 별도의 원시 Transaction.updates 관찰자와 latest 조회에도 취소 정보가 전달되지 않아 XCTest에서 명시적으로 건너뛰었습니다. 이 항목을 통과로 계산하지 않습니다. 운영 골드 환불은 서버 알림으로 처리하며, 지급·중복·환불·환불 철회 등 서버 검사 6개는 통과했습니다. Apple Sandbox에서 실제 서명된 환불 알림을 수신하는 전체 경로는 미검증입니다.

위 구매 검사는 실제 StoreKit 클라이언트 거래와 격리된 가짜 HTTP 지급 서버를 조합합니다. Apple 서버가 서명하는 Sandbox 영수증 검증과 운영 잔고 반영을 대체하지 않습니다. 실제 과금은 발생하지 않았습니다. iOS 26.5의 SKTestSession 내부 오류를 피하기 위해 26.2를 사용했고, 최초 부팅 전에 해당 런타임의 공용 캐시 생성을 완료했습니다. 승인·환불 명령의 비동기 반영은 제한 시간 안에 상태가 바뀌는지 기다린 뒤 검증합니다.

2026-10-07 Apple 서버 알림 추가 검증: 전용 IAP 키를 생성하고 보호된 로컬 폴더에 보관했습니다. Sandbox의 실제 Apple 서명 TEST 알림이 운영 엔드포인트에 도착했고 Apple 전송 결과 SUCCESS / 서버 HTTP 200을 확인했습니다. TEST 알림은 구매·환불을 발생시키지 않으며 거래 테이블은 비어 있습니다. Production TEST 요청은 Apple API HTTP 401로 아직 검증되지 않았습니다.
