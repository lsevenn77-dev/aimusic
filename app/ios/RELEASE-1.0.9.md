# iOS 1.0.9 (28) · 2026-11-18

## 변경 범위

- `4a25aff`의 파티방 상단바 수정 및 기존 1.0.8(27)의 기능을 포함한다.
- iOS의 노래방·토킹룸 WebView에서 방 경로에 한해 웹 공통 로고·검색·알림 상단바와 상단 여백을 숨긴다. 방 내부 제목·나가기·마이크·설정, 네이티브 뒤로가기는 유지한다.
- 문서 시작 시 스타일을 설치해 초기 상단바 노출을 줄이며, 방 경로를 벗어나면 공통 상단바를 복원한다. 웹사이트 자체 코드는 변경하지 않는다.

## 검증

- 수정 전 턴에서 Debug iOS 빌드 성공.
- iPhone 12 시뮬레이터의 실제 WKWebView에서 격리된 방 shell로 노래방·토킹룸 경로의 상단바 숨김과 홈 경로의 복원을 직접 확인했다. 방 내부 조작 표시도 유지했다.
- 실기기는 연결되어 있지 않았다. 운영 방의 음성 연결·마이크 품질을 검증한 것은 아니다.
- Release 아카이브 성공: `/Users/user/Library/Developer/Xcode/Archives/2026-11-18/AIFECT-1.0.9-28.xcarchive`.
- 서명 검증 통과. 번들 `kr.co.aifect.app`, 버전 `1.0.9(28)`, 실행 파일·dSYM UUID `F8186087-12C7-3554-A573-62CF24C087B9` 일치 확인.

## App Store 업데이트 설명

노래방·파티방의 화면을 더 넓고 편하게 이용할 수 있도록 개선했습니다.

• 방 안에서는 로고·검색·알림이 있는 공통 상단바를 숨겼습니다.
• 방 제목, 나가기, 마이크와 소리 설정은 그대로 사용할 수 있습니다.
• 방을 나가면 일반 화면의 상단바가 다시 표시됩니다.
