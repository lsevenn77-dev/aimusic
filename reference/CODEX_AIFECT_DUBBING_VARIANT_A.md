# AIFECT 더빙 페이지 — 1번 시안(A안 가로 탭형) 적용 지시

첨부한 `AIFECT_dubbing_variant_A_reference.png`를 **유일한 디자인 기준 이미지**로 사용해 주세요. 다른 시안(B/C)으로 변경하거나 별도의 대시보드·카드형 레이아웃으로 재해석하지 마세요.

대상: 현행 AIFECT `플레이 > 더빙 > 작품찾기` (참고 URL: `https://aifect.co.kr/#/karaoke/dubbing?tab=discover`). 먼저 현행 코드, 라우트, DB 모델, 기존 녹음·재생 로직 및 `AGENTS.md`를 점검하고, 기존 정상 기능과 데이터를 보존하면서 아래 범위만 수정해 주세요. **운영 배포는 하지 말고**, 로컬 수정·검증 결과를 보고해 주세요.

## 1) 페이지 디자인 및 화면 동작

- 현재의 AIFECT 다크 네이비 색상, 라벤더·민트 포인트, 사이드바, 상단 롤링 배너, `노래 / 더빙 / 둘러보기`, `작품찾기 / 더빙참여 / 내 작업`, 검색창은 유지합니다.
- 검색창 아래 본문을 **왼쪽 대본 목록 약 35% + 오른쪽 선택 대본의 참여 영역 약 65%**의 2열로 배치합니다. 불필요한 큰 소개 배너, 추가 통계 카드, 독립 팝업·패널은 만들지 않습니다.
- **왼쪽**: 커버 썸네일, 제목, 제작자, 배역 수, 간결한 상태표시, `상세보기` 버튼이 있는 스크롤 가능한 리스트. 행 자체를 클릭하면 **오른쪽 패널만 해당 대본으로 갱신**합니다. `상세보기`는 별도 대본 상세페이지로 이동합니다.
- **오른쪽 상단**: 선택된 대본의 작은 커버·제목·제작자·배역 수·`작품 상세보기`를 배치합니다.
- **오른쪽 중단**: `5/6`, `3/6`, `2/6`, `1/6`처럼 **현재 실제 존재하는 진행 단계**를 가로형 탭으로 표시하고, 각 단계 옆에 진행 조합 수를 작게 표기합니다. 진행률 높은 단계부터 정렬합니다. `1/N` 원작자 고정 녹음은 항상 접근 가능해야 합니다. 6인 대본에 `1/2`처럼 다른 분모가 섞이지 않도록 합니다.
- 동일 단계에 조합이 여러 개면 해당 탭 안에서 **각 조합의 실제 참여자 프로필 사진·닉네임·배역**을 간단히 선택할 수 있게 합니다. 조합을 클릭하면 하단 내용만 교체합니다.
- **오른쪽 하단 왼쪽**: 선택한 조합의 녹음 대사를 **대사 한 줄 단위**로 목록화하여 각 줄마다 재생/정지를 제공합니다. 장면 연속 듣기는 보조 기능이며 실제 오디오를 연결합니다.
- **오른쪽 하단 오른쪽**: 아직 비어 있는 배역 목록과 설명을 간결하게 표시하고, 배역 선택 후 `선택한 배역 녹음하기`로 **기존 실제 녹음 화면**에 진입하게 합니다. 이미 찬 배역을 덮어쓰지 않습니다.
- 해당 대본의 상세페이지는 **배역 성격 설명 / 캐릭터별 대본 / 댓글** 중심으로 간결하게 구성합니다. 상세페이지에 참여 조합 패널을 중복 배치하지 않습니다.
- 사진·닉네임·작품·녹음은 실제 데이터에 연결하세요. 스크린샷 속 이름과 숫자는 예시일 뿐 하드코딩하면 안 됩니다. 사용자 고유 내부 ID는 노출하지 마세요.

## 2) 확정한 더빙 참여·완성 운영 규칙

- 이번 구현의 기본 참여 방식은 **기존 조합에 빈 배역을 이어서 녹음하는 방식**입니다. 자동 자유 캐스팅으로 임의 조합을 수백 개 생성하지 마세요.
- 원작자가 먼저 녹음한 **기본 1/N은 영구 유지**합니다. 대본만 등록됐고 원작자 녹음이 아직 없다면 원작 대본은 표시하되 1/N 조합을 가짜로 만들지 않습니다.
- **2인 더빙**: 원작자 1/2 고정 + 다른 참여자 1명이 새 배역을 녹음해 제출하면 2/2로 즉시 완성 처리하고, 완성된 더빙 목록으로 이동합니다. 기본 1/2는 유지합니다.
- **3~6인 더빙**: 필수·선택 배역 구분 없이 **모든 배역 N/N이 찼을 때만** 완성 처리합니다. 5/6은 미완성이고, 6/6이 되면 진행 목록에서 빠져 완성된 더빙 목록으로 이동합니다. 기본 1/N은 계속 유지합니다.
- 사용자가 기존 2/6 등의 조합이 마음에 들지 않으면 **기본 1/6에서 새 조합을 시작**할 수 있습니다. 단, 새 조합 카드는 실제 새로운 배역 녹음이 정상 제출됐을 때만 생성합니다. 기존 조합에 참여하면 2/6 → 3/6으로 **같은 조합의 상태만 갱신**하고 이전 단계의 중복 카드를 남기지 않습니다.
- 진행 중 미완성 조합은 **마지막 실질적 신규 녹음 참여 시점부터 30일간 추가 참여가 없으면 자동 만료·삭제**합니다. 단순 조회·재생·수정·연장 버튼으로 만료 기한을 갱신하지 않습니다. 원작자의 고정 1/N은 삭제 대상이 아닙니다.
- 만료된 조합에서만 사용된 참여 녹음 원본도 삭제합니다. **별도 재사용 보관함에 보존하거나 다른 조합에 자동 재활용하지 않습니다.** 단, 다른 진행 조합·완성작에서 실제 참조 중인 녹음 파일은 해당 콘텐츠가 깨지지 않도록 보존합니다. 참조 관계를 검사한 뒤 삭제하세요.
- 완성 판정(N/N)과 **최종 오디오 파일 렌더링을 분리**합니다. 조합 완료 즉시 완성 상태로 분류하되, 최종 파일은 사용자가 저장·게시할 때 필요 시 렌더링합니다. 미리듣기는 기존 분리된 대사·트랙을 동기 재생하는 방식으로 구현합니다. 자동 대사 타임라인을 기본으로 하고, 완성작 편집 단계에서는 선택한 대사의 시작 시점만 소폭 수동 보정하도록 설계합니다.

## 3) 녹음 공개 설정 / 마이페이지 연동

- **`내 더빙 녹음 공개 설정`은 필수 기능**입니다. 녹음 제출 화면에서 `공개 캐스팅 허용`과 `비공개 보관`을 명확히 구분하고, 공개 시 음성의 재사용·합성·저장·게시 및 기존 완성작 처리에 관한 이용허락을 안내하고 명시적으로 확인받게 하세요. 해당 정책은 법률 검토 대상이므로 포괄적 영구 삭제불가 문구를 임의로 추가하지 마세요.
- 비공개 보관 선택 시 해당 녹음을 공개 참여 조합의 빈 배역에 확정 편입하지 않습니다. 제출 전에 상태를 명확히 안내하고 녹음 중 임시저장 기능을 유지합니다.
- 기존 `마이 > 내 작품`에서 **내 원작 / 내가 참여 중인 녹음 / 내가 제작·게시한 완성작 / 내가 출연한 완성작**의 관계를 확인할 수 있도록 연결합니다. 완성 여부와 녹음 자체의 공개 설정을 혼동하지 말고, 동일 작품 중복 카드를 최소화하세요.

## 4) 예외 처리 및 검증

- 동시에 같은 빈 배역에 여러 사용자가 녹음하는 경우, 제출 시점에 조합 상태를 원자적으로 검증해 중복 배정하지 마세요. 충돌한 사용자에게는 녹음 소실 없이 다른 진행 조합 또는 새 조합으로 참여할 수 있게 안내합니다.
- 모바일에서는 기존 상단 UI를 유지하고 **대본 목록 → 선택 대본의 참여 조합 → 조합 상세·녹음**을 같은 맥락에서 순차적으로 표시해 가로 스크롤·화면 밀림을 방지하세요.
- 2인·3인·6인 대본 각각에서 `1/N 고정`, 새로운 조합 생성, 실제 빈 배역 녹음, 참여 인원 증가, N/N 완료, 완성 탭 이동, 30일 만료, 참조 중 녹음 보존, 모바일 반응형을 확인하세요.
- 버튼만 보이는 가짜 시안으로 끝내지 말고, 기존 코드와 API가 지원하는 기능은 실제 연결하세요. 지원하지 않는 기능이나 DB 변경이 필요하면 임의 데이터 손실 없이 작업하고, 남은 제약을 구체적으로 보고하세요.
- 완료 후 변경 파일, 적용 기능, 테스트 결과, 미구현 사항을 요약하고 PC·모바일 화면을 확인할 수 있는 스크린샷을 첨부하세요. **사용자가 별도로 요청하기 전에는 배포하지 마세요.**
